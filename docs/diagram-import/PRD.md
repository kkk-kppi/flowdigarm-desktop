**版本：** 0.1

**状态：** **待实现**

**发布日期：** 未发布

**适用平台：** Windows 10/11、macOS（Intel/Apple Silicon）

**关联技术设计：** [`TDS.md`](./TDS.md)

**设计来源：** [`../superpowers/specs/2026-08-01-editable-visual-diagram-import-design.md`](../superpowers/specs/2026-08-01-editable-visual-diagram-import-design.md)

> **待实现声明：** 本文描述的是规划中的产品能力，不代表当前应用已经支持视觉流程图导入。本文全部功能项在实现、验证并更新状态前均视为“待实现”。

## 1. 背景

用户已有的流程图可能来自 PDF、SVG、截图、扫描件或其他绘图软件。当前应用只能打开自身 `.flowdiagram` 文档，用户需要手工重新绘制已有流程图，成本高且容易遗漏节点、连线和文字。

本需求增加“可编辑通用视觉流程图导入”：系统从源文件中识别节点、连线、文字、页面及容器关系，生成可编辑的流程图草稿。用户在预览工作区确认和修正后，一次性写入当前 `.flowdiagram`。

## 2. 产品目标

### 2.1 核心目标

1. 将 SVG、PDF、PNG、JPEG、WebP 中的流程图转换为可编辑图元。
2. 优先还原结构与语义，不以逐像素复制为主要目标。
3. 默认在本地完成解析、OCR、图形识别和结构推理。
4. 通过预览校对处理低置信度和歧义结果。
5. 用户确认导入后，只产生一条可撤销、可重做的用户历史。
6. 使用可量化样本集验证预览确认后的结构与语义还原度达到 90%。

### 2.2 用户价值

- 减少从现有图纸重新绘制的时间。
- 保留导入后继续编辑、排版、保存和导出的能力。
- 让识别问题显式可见并可修正，而不是静默生成错误结果。
- 在默认不上传源文件的前提下保护业务图和文档隐私。

### 2.3 非目标

- 不承诺逐像素达到 90% 视觉相似度。
- 不承诺首期识别任意工程图、思维导图、网络拓扑或自由手绘内容。
- 不把导入结果作为不可编辑的整页图片直接交付。
- 不在当前安全基线下上传用户图文件或元数据。
- 不在首期实现 `.vsdx`、`.drawio` 等原生结构格式；它们属于后续扩展。
- 不在确认导入时生成数百条逐元素撤销记录。

## 3. 用户与场景

| 用户 | 典型来源 | 核心诉求 |
|---|---|---|
| 业务分析师 | PDF、截图、扫描件 | 快速恢复节点、分支、文字和流程方向 |
| 技术人员 | SVG、架构图 PDF | 保留连接关系、分组和页面结构并继续编辑 |
| 文档作者 | 报告中的流程图图片 | 提取可编辑内容，统一到当前文档样式 |
| 流程维护人员 | 历史流程资料 | 在旧图基础上增删节点并重新发布 |

### 3.1 主要用户故事

- 作为业务分析师，我希望导入一份流程图 PDF，并在确认后继续修改节点和连线。
- 作为技术人员，我希望矢量文字直接提取，避免 OCR 改坏原有文本。
- 作为流程维护人员，我希望系统高亮断线和低置信度文字，以便集中修正。
- 作为文档作者，我希望多页 PDF 按原顺序生成多个应用页面。
- 作为任意用户，我希望一次撤销完整取消刚才的导入。
- 作为重视隐私的用户，我希望默认离线处理，未经确认不发送任何内容。

## 4. 产品原则

1. **可编辑优先：** 节点、连线、文字和层级应转换为领域图元。
2. **确定性优先：** 可直接解析的矢量和文字不交给模型猜测。
3. **本地优先：** 默认路径不依赖网络。
4. **问题显式：** 未识别和低置信度内容进入问题列表，不静默丢弃。
5. **确认后提交：** 预览阶段不修改当前 `.flowdiagram`。
6. **原子历史：** 确认导入是一次用户行为，一次撤销、一次重做。
7. **指标可验证：** 真实还原度以人工标注标准答案计算，不使用系统置信度冒充准确率。

## 6. 用户流程

```text
文件 → 导入流程图
  → 选择源文件
  → 本地解析与识别
  → 查看识别摘要
  → 进入预览校对
  → 处理阻断问题和低置信度项
  → 确认导入
  → 一次性修改当前 .flowdiagram
  → 可撤销/重做
```

### 6.1 取消流程

- 文件选择取消：不创建导入会话，不修改文档。
- 识别中取消：停止任务并清理临时数据，不修改文档。
- 预览中取消：关闭会话，不修改文档历史、revision 或 dirty。
- 提交失败：保留预览结果供修正和重试，当前文档保持原状。

## 8. 预览交互规格

### 8.1 页面结构

| 区域 | 内容 | 主要操作 |
|---|---|---|
| 来源区 | 原始页面 | 缩放、平移、框选、定位 |
| 重建区 | 可编辑导入草稿 | 选择、修改、重连、拆分、合并 |
| 问题区 | 页面、问题、属性和置信度 | 筛选、定位、确认、重试 |

### 8.2 置信度展示

初始建议阈值：

| 级别 | 范围 | 产品行为 |
|---|---:|---|
| 高 | `>= 0.90` | 正常显示，默认无需处理 |
| 中 | `0.70-0.89` | 黄色提示，建议检查 |
| 低 | `< 0.70` | 红色提示，要求确认或修正 |
| 无候选 | 无 | 保留来源区域并列为问题 |

阈值必须通过验收样本校准。界面应称为“识别置信度”或“完整度”，不得称为真实还原准确率。

### 8.3 确认按钮

- 无领域非法结果时可进入确认。
- 存在结构性阻断问题时默认禁用确认并提供定位入口。
- 可忽略的非结构问题必须由用户明确确认“仍然导入”。
- 确认期间防止重复提交。

### 8.4 无法结构化区域

系统建议将无法结构化区域降级为图片节点时，必须先取得用户确认：

- 用户同意：该区域映射为图片节点，并在导入报告中标记为不可结构化内容。
- 用户不同意：该区域保持“未解决”，不得自动删除或自动改成其他结果。
- 用户可选择手动标注为节点、文字、连线、容器或分组。
- 用户可调整区域后执行局部重新识别。
- 用户可明确选择排除该区域；系统记录排除范围和原因，并降低完整度及验收评分。
- 如果排除导致断线、非法层级、悬空引用或其他领域非法结果，确认按钮继续保持阻断状态。
- 用户也可以取消整个导入，当前文档保持不变。

## 9. 质量指标

### 9.1 还原度

```text
结构与语义总分 =
  节点识别与类型准确率 × 30%
+ 连线端点与方向准确率 × 30%
+ 文字内容及归属准确率 × 25%
+ 页面、容器和分组准确率 × 15%
```

验收目标：

- 预览确认后的结果总分不低于 90%。
- 任一核心分项不低于 85%。
- 自动结果与人工修正后结果分别统计。
- 召回率纳入评分，遗漏对象计入损失。
- 样式、颜色和精确位置不进入主要 90% 指标。

### 9.2 可靠性

- 取消、失败和应用异常不得部分修改当前文档。
- 未知内容不得静默丢失。
- 同一输入及相同识别组件版本结果可复现。
- 导入、撤销、重做、保存和重开后的文档结构一致。

### 9.3 性能

阶段一必须建立目标设备基线，测量：

- 单页和多页矢量 PDF 处理时间。
- 100、500、2000 个识别元素的预览响应。
- 峰值内存、临时文件和安装包增量。
- 原子提交、撤销和重做耗时。
- 后台识别期间现有编辑器交互响应。

具体性能门槛在基线样本和目标设备实测后进入发布标准，不以未测数值作承诺。

## 10. 安全与隐私

- SVG 不执行脚本、事件处理器或外部资源。
- PDF 不执行嵌入动作。
- 检查文件魔数、扩展名、压缩展开大小和资源数量。
- 图片解码、OCR 和模型任务受内存及时间限制。
- 临时数据使用随机会话目录，完成、取消和过期后清理。
- 日志不记录完整源文件、识别图片或敏感文字。
- 当前版本不实现或启用网络上传。

## 11. 验收场景

1. 导入标准 SVG，节点、文字和连接关系可编辑。
2. 导入多页矢量 PDF，页面顺序正确，每页生成对应应用页面。
3. 原生矢量文字直接提取，不经过 OCR。
4. 断线、无归属文字和未知形状出现在问题列表并可定位。
5. 用户修改一个节点类型和一条连线后，问题状态重新计算。
6. 取消预览后当前文档、dirty、revision 和历史不变。
7. 确认导入数百个元素后，历史只增加一条记录。
8. 导入多页后切换页面，一次撤销仍完整恢复导入前文档。
9. 撤销后一次重做恢复完全相同的导入结果。
10. 提交校验失败时不进入历史且预览会话保留。
11. 未知元素降级保留，不静默消失。
12. 拒绝图片降级后，区域保持未解决并提供手动结构化、重识别、明确排除和取消入口。
13. 明确排除结构关键区域造成断线或非法层级时，系统阻止确认。
14. 标准验收集的预览确认后综合分达到 90%，各核心分项达到 85%。

- 需求追踪中所有 P0 项有实现和自动化证据。
- 完整标注验收集通过，不以少量截图替代评分。

## 13. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 通用位图差异过大 | 自动识别率不稳定 | 分阶段支持、预览修正、按难度分层验收 |
| 连接关系误判 | 流程语义错误 | 连线关系高权重、断线阻断、人工确认 |
| OCR 正确但归属错误 | 节点或边标签错误 | 分开计算文字内容与归属准确率 |
| 模型体积和性能 | 安装包大、低配设备慢 | 基础算法可独立运行，模型作为可选增强 |
| 跨页导入破坏撤销语义 | 无法一次恢复 | 文档级命令和全局行为协调器先行 |
| 未知内容丢失 | 结果不完整 | 通用路径优先、图片降级需确认、明确排除进入报告并计入评分 |
| 指标不可证明 | 无法验收 90% | 标注样本和评分工具先于识别调优 |
