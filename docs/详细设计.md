# 桌面流程图编辑器 详细设计

**版本：** 4.1  
**状态：** 最终技术规格（已对齐原型 HTML v2）

## 1. X6 插件使用边界

| 插件 | 使用方式 | 禁止事项 |
|---|---|---|
| Selection | 框选、多选、选择框视觉 | 不作为领域选择真源 |
| Dnd | 形状库拖入预览 | 不直接持久化模板 Cell |
| Snapline | 拖动辅助线 | 不记录为命令 |
| Keyboard | 快捷键分发 | 文本编辑态不拦截输入 |
| Clipboard | 可作为内部复制辅助 | 领域层负责新 ID、内部边、粘贴命令 |
| Transform | 控制点和手势 | 手势结束归并为一个命令 |
| Scroller | 平移、页面视区、分页视觉 | 不以 px 作为文档单位 |
| History | 可禁用或调试 | 不允许驱动用户撤销/重做 |

## 2. 领域模型与持久化

### 2.1 文件格式

文件扩展名为 `.flowdiagram`，UTF-8 JSON。`schemaVersion` 只增不改；加载旧版本时执行迁移后再进入编辑器。

**核心数据结构**：

```typescript
interface DiagramDocument {
  schemaVersion: 1
  id: string
  name: string
  pages: DiagramPage[]
}

interface DiagramPage {
  id: string
  name: string
  type: 'foreground' | 'background'
  backgroundPageId?: string
  unit: 'mm' | 'cm' | 'in' | 'pt' | 'px'
  pageSize: { preset?: PaperPreset; width: number; height: number }
  orientation: 'portrait' | 'landscape'
  defaultConnector: 'straight' | 'orthogonal' | 'curved'
  showLineJumps: boolean
  canvas: { gridSize: number; background: string }
  nodes: DiagramNode[]
  edges: DiagramEdge[]
}
```

### 2.2 文件与恢复

- 用户文件为 UTF-8 `.flowdiagram` JSON
- 保存：写入同目录临时文件，fsync 后原子替换目标文件
- 自动恢复：文档变脏后 2 秒防抖写 SQLite 快照；显式保存更新最近文件并清除恢复提示
- 文件加载拒绝非法 schema、未知单位、NaN、负宽高、超过限制的节点/边数量和超大图片

## 3. 坐标、单位与渲染

### 3.1 三层坐标

```text
输入与显示：cm / mm / in / pt / px
      ⇅ MeasurementService
文档坐标：pt
      ⇅ ViewportTransform
SVG/DOM：CSS px
```

**固定换算**：
- `1 in = 72 pt`
- `1 cm = 72/2.54 pt`
- `1 mm = 72/25.4 pt`
- `1 CSS px = 72/96 pt`

A4 保存为 `595.276 × 841.89 pt`。单位切为 cm 后，文件与几何不变，只有标尺、输入控件和属性面板重新格式化。

### 3.2 X6 与 WebView

X6 Cell 使用 pt 数值。视口变换为：

```text
screenPx = panPx + documentPt × 96/72 × zoom
```

X6 Graph 缩放值为 `96/72 × zoom`。浏览器的 `devicePixelRatio` 不进入文档或命中逻辑；它仅影响显示器物理像素。PNG 导出使用独立的 96/150/300 DPI 栅格倍率。

HTML 覆盖式文本编辑框需复用相同 `ViewportTransform`，并且只换算一次，避免图缩放与 DOM 缩放叠乘。

### 3.3 标尺与视图

- 顶部水平和左侧垂直标尺为非持久化叠层
- 标尺从屏幕坐标反算到 pt 后转当前单位
- 刻度采取 1/2/5×10^n，主刻度 60–120 CSS px，次刻度 8–20 CSS px
- 支持标尺、网格、分页符、参考线独立显示/隐藏；这些开关不进入撤销历史
- "适应窗口/页面/选择/内容"仅修改视口，不改变文档

## 4. 页面与打印

### 4.1 统一页面设置

页面设置以右侧属性面板的"页面设置"标签页呈现，包含两个区域：

**页面属性**：

| 字段 | 说明 |
|---|---|
| 纸张大小 | A3、A4（默认）、A5、Letter |
| 方向 | 纵向（默认）、横向 |

**连线配置**：

| 字段 | 说明 |
|---|---|
| 连线类型 | 直线、直角（默认）、曲线 |
| 默认箭头 | 无、单向（默认）、双向 |
| 自动连线标签 | 开关（默认开启） |
| 连线跳线 | 开关（默认关闭） |

页面设置修改后打包为一个 `UpdatePageCommand`；取消不产生更改。边的连接类型可覆盖页面默认值。

### 4.2 分页符

分页符根据绘图页和打印页尺寸计算分块边界，以虚线覆盖在页面上。它是视图设置，不修改文档也不写撤销历史。若绘图页大于可打印区域，显示 2×2、3×1 等实际打印拼接边界。

### 4.3 背景页

前景页最多引用一个背景页。渲染、打印和导出按背景页后前景页绘制；背景页不能形成循环引用。背景页内容不可在前景页直接选择，需切换到背景页编辑。

## 5. 画布交互

### 5.1 选择与操作

- 单击选择；Shift/Ctrl/Cmd 修改选择集；框选选择相交或完全包含的图元
- 拖拽、缩放、旋转、复制粘贴、删除、对齐、层级调整均通过命令执行
- 普通单击带超链接图元仍选择；Windows `Ctrl` 或 macOS `Cmd` + 单击才调用安全外链打开

### 5.2 连接

- 节点注册可连接端口；边保留源/目标端口与可选拐点
- 默认连接类型继承页面设置；边可独立改为直线、直角或曲线
- 直角连线提供基础锚定与人工拐点；跳线只表示交叉视觉，不创建连接

### 5.3 文本

- 双击或 Enter/F2 编辑；Esc 取消，Ctrl/Cmd+Enter 或失焦提交
- 文本编辑使用 HTML 输入层，提交后写回 `TextEditCommand`
- 多选样式读取为 `value | mixed | undefined`；点击控件即统一覆盖选中目标
- 竖排采用逐字排版，不做整块旋转

### 5.4 格式刷、组合与容器

- 格式刷复制填充、边框、阴影、文字、文本块、段落；不复制位置、大小、内容、链接、形状类型、业务数据
- 单击为单次，双击/锁定为连续，Esc 退出；一次多目标应用只产生一条历史记录
- 组合/容器都可解除，且成员原有 ID 与数据保留

## 6. 查找替换、菜单与形状库

### 6.1 查找替换

查找替换以右侧属性面板形式呈现（点击 Ribbon"查找替换"按钮时显示），包含：

- **查找输入框**：输入查找内容
- **替换输入框**：输入替换内容
- **选项按钮**：区分大小写（Aa）、全词匹配（Ab|）、搜索范围（当前页/全部页面）
- **操作按钮**：查找下一个（蓝色高亮）、替换、全部替换
- **帮助按钮**：`?` 图标
- **关闭按钮**：关闭查找替换面板
- **状态提示**：显示匹配数量（如"未找到匹配项"或"找到 N 个匹配"）

查找范围：当前页或全图；支持大小写与全词；只查形状文本和边标签。"全部替换"先显示匹配数量与目标预览，然后作为一个可撤销命令执行。

### 6.2 右键菜单

右键菜单按空白区、节点、边、多选、容器生成，包含复制、粘贴、文本样式等操作；菜单只调用既有命令，不重复业务逻辑。

### 6.3 形状库

形状库位于左侧面板（320px），包含搜索框和分类列表：

| 分类 | 形状 |
|------|------|
| 基本形状 | 矩形、圆角矩形、椭圆、菱形、平行四边形、梯形、三角形、六边形 |
| 流程图 | 开始/结束、流程、判定、数据 |
| 连线 | 直线、折线、曲线 |

形状以 4 列网格展示，选中形状高亮（蓝色左边框 + 蓝色背景）。常用形状按本机 SQLite 使用次数排序，展示前 20；新用户使用预置基础顺序补足。统计不上传。

## 7. 用户行为级撤销/重做

不使用 X6 属性变更历史。每个 `EditorCommand` 保存可逆的领域更改；一次用户意图只产生一条记录：拖拽、文本编辑会话、批量样式、格式刷、全部替换、组合、粘贴、删除和页面设置各一条。

连续手势在 pointer down 到 pointer up 间合并；IME 组合过程不入栈；执行新命令清空重做栈。视图操作、标尺开关、分页符开关不进入历史。

## 8. 命令接口与数据契约

### 8.1 命令接口

```typescript
interface EditorCommand {
  id: string
  label: string
  apply(document: DiagramDocument): DiagramDocument
  revert(document: DiagramDocument): DiagramDocument
}

interface CommandHistory {
  execute(command: EditorCommand): void
  undo(): boolean
  redo(): boolean
  readonly canUndo: boolean
  readonly canRedo: boolean
}
```

命令输入和快照使用不可变领域对象；不引用 Vue ref、DOM 或 X6 Cell。执行成功后写入历史；执行失败不改变文档或历史。

### 8.2 命令字典

| 命令 | 输入 | 一条历史边界 | 反向操作 |
|---|---|---|---|
| CreateCells | 节点/边 | 一次拖入/粘贴 | 删除创建项 |
| DeleteCells | IDs 与快照 | 一次删除 | 恢复全部快照 |
| MoveCells | before/after 位置 | pointer down→up | 恢复 before |
| ResizeCells | before/after bbox | 一次缩放手势 | 恢复 before |
| RotateCells | before/after angle | 一次旋转手势 | 恢复 before |
| EditText | before/after text | 一次编辑会话 | 恢复 before |
| ApplyStyle | 每单元 before/after patch | 一次控件或高级对话框应用 | 恢复 before |
| ApplyFormatPaint | 源样式、目标 before/after | 每次应用 | 恢复 targets |
| Connect/Reconnect | 边 before/after endpoint | 一次连接手势 | 恢复 before |
| ReplaceAllText | 所有命中 before/after | 一次全部替换 | 恢复所有文本 |
| Group/Ungroup | 父子关系快照 | 一次结构操作 | 恢复关系 |
| UpdatePage | 页面 before/after | 一次应用/确定 | 恢复页面 |

### 8.3 JSON 约束

- `schemaVersion` 为整数，加载器只接受已知版本
- ID 为 UUID v4；同一文档内节点、边、页 ID 唯一
- 所有 pt 长度必须为有限数且范围 `0..1_000_000`；允许位置为负
- 颜色使用 `#RRGGBB` 或 `#RRGGBBAA`；URL 保存前以白名单校验
- `backgroundPageId` 必须指向背景页，且不能形成循环
- 边的端口引用必须存在；缺失端口的旧文件迁移为节点中心锚点并给出只读警告

### 8.4 平台契约

```typescript
interface DesktopPlatform {
  openDiagram(): Promise<{ path: string; document: DiagramDocument } | null>
  saveDiagram(input: { path?: string; document: DiagramDocument }): Promise<string | null>
  exportDiagram(input: ExportRequest): Promise<string | null>
  openExternalLink(url: string): Promise<void>
  readRecoverySnapshot(): Promise<DiagramDocument | null>
  writeRecoverySnapshot(document: DiagramDocument): Promise<void>
}
```

前端只调用此接口；Rust 端再次执行 URL、路径和文件大小校验。保存接口成功才更新最近文件与脏状态。

## 9. SQLite 数据库设计

### 9.1 数据边界

流程图主体保存为 `.flowdiagram` JSON；SQLite 只保存本机元数据、恢复快照、偏好、最近文件和形状使用统计。SQLite 不取代用户显式保存的图文件。

### 9.2 数据库与迁移

- 文件：应用数据目录下 `flowchart-editor.db`
- 启用 `PRAGMA foreign_keys = ON`、`journal_mode = WAL`、`busy_timeout = 5000`
- 使用 `schema_migrations(version INTEGER PRIMARY KEY, applied_at INTEGER NOT NULL)` 记录迁移
- 所有时间为 Unix 毫秒 UTC；布尔值为 0/1；JSON 字段必须 UTF-8 且可解析

### 9.3 表结构

| 表 | 写入时机 | 读取时机 | 清理规则 |
|---|---|---|---|
| app_settings | 修改主题、面板、视图、导出偏好 | 应用启动/设置打开 | 仅"重置应用设置"删除 |
| recent_documents | 打开或保存成功 | 文件菜单、启动页 | 保留置顶项及最近 50 条 |
| recovery_snapshots | 文档脏状态 2 秒防抖 | 启动、异常恢复 | 成功显式保存后删除对应快照；用户丢弃时删除 |
| shape_usage | 拖入、创建、复制形状成功 | 常用形状面板 | 永久本地保存；重置应用数据时删除 |
| window_state | 窗口移动/缩放结束 | 启动时恢复 | 无需自动清理 |
| user_templates | 用户保存/更新模板 | 模板面板 | 用户显式删除 |

### 9.4 设置键定义

| setting_key | value_json | 默认值 |
|---|---|---|
| `theme.mode` | `"system" | "light" | "dark"` | `"system"` |
| `editor.showRulers` | boolean | true |
| `editor.showGrid` | boolean | false |
| `editor.showGuides` | boolean | true |
| `editor.showPageBreaks` | boolean | false |
| `editor.defaultZoom` | number，0.1–4 | 1 |
| `editor.defaultPageUnit` | `"mm" | "cm" | "in" | "pt" | "px"` | `"mm"` |
| `editor.defaultConnector` | `"straight" | "orthogonal" | "curved"` | `"orthogonal"` |
| `editor.recentLimit` | integer，1–100 | 50 |
| `export.pngDpi` | 96/150/300 | 150 |

## 10. 形状与连线规格

### 10.1 首批内置形状

| 分类 | 形状 | 默认尺寸 pt | 默认端口 |
|---|---|---:|---|
| 基本形状 | 矩形、圆角矩形、圆形、椭圆、三角形、菱形 | 120×72 | 上/右/下/左 |
| 流程图 | 流程、判定、终止、子流程、文档、数据流 | 140×72 | 上/右/下/左 |

所有形状由 `ShapeDefinition` 注册：`type`、SVG markup/path、默认尺寸、最小尺寸、端口规则、文本区域、默认样式、是否可作为容器。

所有形状由 `ShapeDefinition` 注册：`type`、SVG markup/path、默认尺寸、最小尺寸、端口规则、文本区域、默认样式、是否可作为容器。

### 10.2 形状约束

- 最小宽高：文本框 24×20 pt，其余默认 36×24 pt；图片最小 24×24 pt
- 拖拽缩放时保持最小尺寸；Shift 保持图片/椭圆比例；Alt 从中心缩放
- 文本区域默认为形状内接矩形减边距；菱形使用安全内接区域，避免文字压到尖角
- 旋转保存为度数 0–359.999；文本横排随形状旋转，竖排仍沿形状局部坐标排布

### 10.3 端口与连接校验

端口位置为形状局部 bbox 的上、右、下、左中点。悬停端口高亮；可连接规则：源端和目标端均允许连接、目标不是同一端口、容器不作为连接端点。连接到节点主体时自动选择距离最近的允许端口。

边字段：源/目标节点和端口、连接类型、拐点、箭头样式、标签、样式、链接。删除节点时默认删除其关联边；复制一组图元时，仅复制源和目标均在复制集内的边。

### 10.4 连线渲染与编辑

| 类型 | 路径 | 编辑规则 |
|---|---|---|
| 直线 | 源端到目标端 | 无中间拐点 |
| 直角 | H/V 分段 | 支持添加/拖拽拐点；基础自动锚定 |
| 曲线 | 三次贝塞尔 | 显示两个控制柄，拖动控制曲率 |

首期直角路由仅选择简单可行路径：水平优先、垂直优先、用户指定拐点；不承诺绕开所有节点。跨线跳线只在几何相交、无共同端点的边上绘制小弧，不改变拓扑。

## 12. 选择与拖拽状态机

```text
Idle → PointerDown → DragThreshold? → Dragging → PointerUp → Idle
                 └→ ClickSelection ──────────────────────────────┘
```

- 拖拽阈值为 3 CSS px；阈值内松开按单击处理
- 单击空白清空选择；拖拽空白形成框选
- 选中节点拖动时显示对齐辅助线和可选网格吸附；指针松开才创建一条 `MoveCellsCommand`
- 选中边显示端点和拐点；拖动端点执行重连，拖动中间点执行拐点更新
- 容器移动时成员一起移动；组合移动时子节点一起移动；成员单独拖出容器时由"移出容器"命令显式完成

## 13. 文本编辑交互

1. 双击节点、F2 或 Enter 建立编辑会话，覆盖式编辑框与节点文本块重合
2. 编辑中允许中文 IME；组合输入过程不得写入撤销栈
3. `Esc` 恢复会话开始前文本；失焦、Ctrl/Cmd+Enter、单击画布提交
4. 会话提交仅创建一条 `EditTextCommand`；文本未变更不创建命令
5. 节点文字按文本块的边距、方向、对齐、段前/后、行距布局；溢出策略为裁剪并在属性面板提示，不自动扩大节点

## 14. 格式与格式刷

### 14.1 多选样式

工具栏读取选中图元的聚合值：一致则显示值，不一致显示混合态，无文本则禁用文本控件。字体、字号、粗体、斜体、下划线、文字色、水平/垂直对齐、文本方向、文本背景、边距和段落间距均可批量设置。

一次控件变更将全部目标写入一个 `ApplyStyleCommand`，撤销一次恢复全部目标的原值。

### 14.2 格式刷

- 单击格式刷：捕获来源样式，下一次点击目标后退出
- 双击或按锁定：连续模式，应用多个目标，Esc 退出
- 复制：填充、边框、阴影、字体/文字、文本块、段落
- 不复制：ID、位置、尺寸、旋转、文本内容、图片、链接、端口、业务数据、组合/容器关系
- 多目标框选后应用仍为一个命令

节点填充支持颜色与透明度；阴影支持颜色、透明度、X/Y 偏移和模糊。边样式支持颜色、宽度、透明度、实线/虚线/点线/点划线、起始箭头和结束箭头；这些样式均支持多选批量修改。

## 15. 排列算法

- 选择锚点为选择序列第一个图元
- 水平方向对齐（左/中/右）和垂直方向对齐（上/中/下）以锚点 bbox 计算目标坐标
- 两两形状之间的水平等距排列和垂直等距排列：按轴坐标排序，固定端点，`gap=(last.start-first.end-sum(middle.size))/(n-1)`；gap<0 则拒绝并提示
- 自动连线按选择序列创建 n-1 条边；整体为 `AutoConnectCommand`

## 16. 安全与性能

- 外链只允许 `https:`、`http:`、`mailto:`，前端与 Rust 双重校验
- 首期性能目标：500 节点、800 边的编辑、选择、拖拽保持可交互；视口外图元可延迟更新
- 导入时限制文件大小、图片大小、文本长度及节点/边数量
- macOS 发布必须具备签名与公证；Windows 安装包必须建立签名与升级策略

## 17. 用户可见错误提示

| 场景 | 提示 | 文档是否改变 |
|---|---|---|
| 打开损坏文件 | "文件格式无效，未打开文件。" | 否 |
| 保存失败 | "无法保存，原文件未被覆盖。" | 否 |
| 禁止协议 | "仅支持 http、https、mailto 链接。" | 否 |
| 连接无效 | "此形状不接受该连接。" | 否 |
| 文本替换为 0 | "未找到匹配文本。" | 否 |

## 18. UI 组件规格

### 18.1 标题栏

高度 28px，包含应用图标、应用名称"流程图编辑器"、当前文件名、窗口控制按钮（全屏、最大化、最小化）。

### 18.2 菜单栏

高度 28px，7 个菜单项：文件、编辑、视图、插入、格式、工具、帮助。每个菜单项有 `?` 帮助图标。

### 18.3 紧凑工具栏

高度 48px，单行紧凑布局，分组：

| 分组 | 控件 |
|------|------|
| 操作 | 撤销、重做 |
| 粘贴板 | 复制、剪切、粘贴、格式刷 |
| 字体 | 字体下拉、字号下拉、粗体/斜体/下划线/删除线、文字颜色/文字背景色 |
| 段落对齐 | 顶端/垂直居中/底端对齐、左/居中/右对齐 |

分组之间用竖线分隔。视图控制、页面设置、查找替换放在右侧面板标签页中。

### 18.5 页面标签栏

高度 32px，包含当前页面标签（可关闭）、添加页面按钮（+）、缩放控制（滑块 + 百分比）。

### 18.5 左侧图元库

宽度 220px，可折叠。标题"图元"，搜索框，分类列表（基本形状/流程图），3 列网格。底部有"更多形状..."按钮。

| 分类 | 形状 |
|------|------|
| 基本形状 | 矩形、圆角矩形、圆形、椭圆、三角形、菱形 |
| 流程图 | 流程、判定、终止、子流程、文档、数据流 |

### 18.6 右侧面板

宽度 280px，可折叠（左侧有折叠按钮），包含 2 个可见标签页 + 查找替换模式：

- **属性**（默认）：节点信息（类型/名称/ID）、几何（X/Y/宽/高）、样式（填充色/边框色）、文本（内容/字体/字号/粗斜下划删除线/字体颜色/背景色/对齐方式）
- **页面设置**：页面属性（纸张大小/方向）、连线配置（连线类型/默认箭头/自动连线标签/连线跳线）
- **查找替换**（从菜单触发）：隐藏标签栏，标题变为"查找替换"，显示查找/替换输入框和"返回属性"链接

### 18.7 状态栏

高度 24px：
- 左侧：选中信息（"已选择 N 个图元"）+ 坐标（X: xxx  Y: xxx）
- 右侧：页码（"页 1/1"）、缩放下拉（50%/75%/100%/125%/150%/200%/适应屏幕）、网格状态按钮、对齐状态按钮、保存状态指示

### 18.9 导出对话框

模态对话框 480px 宽，包含：标题"导出"+ 帮助/关闭按钮、页面范围单选、格式卡片（SVG/PNG/PDF）、文件名输入、保存位置浏览、取消/导出按钮。

## 19. 验收场景

- 给三个不同样式节点多选加粗，历史只加 1；撤销后全部复原
- 单击格式刷一次后自动退出；连续模式应用三个目标、Esc 退出，历史加 3（每次独立应用一次）
- 将单位 cm 改 mm，节点 pt 坐标相同，标尺标签改变
- 开启分页符，绘图页比打印页大时显示分块虚线；关闭后消失
- 全图替换 10 个命中项，撤销一次恢复 10 个原文本
