# 用户指南

本指南适用于 Windows 10/11 与 macOS 桌面版。应用离线工作，流程图保存在本机 `.flowdiagram` 文件中。

## 快速上手（3 分钟流程）

1. 在左侧「图元库」双击「矩形」，再双击「菱形」，画布中央会创建并选中形状。也可以把形状拖到指定位置。
2. 双击矩形，输入“开始”，按 Ctrl+Enter（macOS 为 Cmd+Enter）提交；双击菱形输入“是否通过”并提交。Esc 会取消本次文字编辑。
3. 悬停矩形，从出现的四边端口拖到菱形端口或主体，创建连接线。选中连线后可在右侧「属性」中选择「直线」「直角」或「曲线」。
4. 选择「文件」->「保存」，首次保存选择位置并确认 `.flowdiagram` 文件名。后续可按 Ctrl+S（macOS 为 Cmd+S）原地保存。
5. 选择「文件」->「导出」，格式选「PNG」，分辨率选 96、150 或 300 DPI，点击「浏览」选择保存位置，再点击「导出」。成功后会显示实际输出路径。

## 文件

「文件」菜单提供「新建」「打开」「保存」「另存为」「最近文件」「导出」和「页面设置」。打开文件会校验 UTF-8、JSON、schema、ID、几何、页面引用、端口与链接协议；文件选择取消或校验失败都不会替换当前文档。最近文件按置顶优先、最近使用排序，悬停可查看完整路径；文件不存在时会提示并移除该项。

保存使用同目录临时文件和原子替换。没有扩展名时自动补 `.flowdiagram`，其他扩展名会被拒绝。若显示「无法保存，原文件未被覆盖。」，请检查目录写权限、剩余空间和文件是否被其他程序占用，当前文档仍保留未保存状态。

新建、打开其他文件或关闭窗口前，如果当前文档有未保存更改，会出现「未保存的更改」，可选择保存、不保存或取消。脏文档在最后一次变化约 2 秒后写入本机恢复快照；下次启动可恢复或经二次确认丢弃。恢复后的标题仍带未保存标记，显式保存成功后才清理对应快照。

## 页面

- 单击底部页面标签切换页面；每页保留独立视口和撤销栈，切换本身不可撤销。
- 单击标签栏末尾「+」新建页面；双击页签重命名，Enter 或失焦提交，Esc 取消；页数大于 1 时单击「×」并确认删除。
- 至少保留一页。被前景页引用的背景页不能删除，背景页内容必须切换到该背景页后编辑。
- 在右侧「页面设置」选择纸张、方向、单位、背景色、背景页、默认连接线、箭头、自动连线标签和连线跳线；点击「应用」把全部变化记为一条历史，点击「重置」恢复显示值。
- 「自动调整大小」按当前内容外接矩形和边距设置页面；空页面时按钮禁用并显示「页面无图元」。

## 编辑

Ctrl/Cmd+Z 撤销，Ctrl+Y（macOS 为 Cmd+Shift+Z）重做；产生新编辑后，原重做分支会被清空。一次拖动、缩放、旋转、文字会话、批量样式、格式刷应用、粘贴、删除、组合或页面设置分别形成一条历史。缩放、平移、选择、切换页和显示开关不进入历史。

Ctrl/Cmd+C、X、V 复制、剪切、粘贴，Ctrl+D 重复；Delete/Backspace 删除选中图元。系统剪贴板不可用时会降级到应用内副本。菜单项禁用时悬停可查看原因，例如「剪贴板为空。」或「请先选择图元。」。

单选节点后可在右侧「属性」展开「业务数据」，以 JSON 对象编辑扩展数据。点击「应用」校验并生成一条「业务数据」撤销记录，点击「重置」放弃草稿；数组、字符串、数字等非对象值会提示「业务数据必须是 JSON 对象。」。多选或只选择连线时该编辑器禁用。

## 图元

图元库提供「基本形状」与「流程图」分类以及本机「常用」列表。可搜索名称、展开分类、拖入画布，或双击/按 Enter 在视口中心创建。库中可直接创建矩形、圆角矩形、圆形、椭圆、三角形、菱形、流程、判定、终止、子流程、文档和数据流；「插入」菜单还提供「文本框」「连接线」和「外部图片」。

单击选择，Ctrl/Cmd+单击增减多选，空白处拖动框选。选择序列的第一个节点是对齐锚点。拖动节点移动；使用选择手柄缩放和旋转；图片和椭圆按住 Shift 缩放保持比例。Delete/Backspace 删除选中内容，删除节点时关联边一并删除。

「插入」->「外部图片」支持不超过 5 MiB 的 PNG、JPEG 和 WebP。应用校验扩展名、魔数和解码尺寸；SVG 或内容与扩展名不一致时拒绝导入。图片按原比例居中创建并嵌入图文件。

复制会保留源集合内部的连线和容器层级，粘贴生成新 ID 并逐次偏移。系统剪贴板不可用或外部内容校验失败时会显示降级提示，并继续使用已有应用内副本。

## 形状与连线

悬停节点显示上、右、下、左四个端口。从端口拖到另一节点的端口，或拖到节点主体由应用选择最近端口。当前不允许自环、悬空端点或把容器作为连接端点。选中边后可拖动端点重新连接，拖动拐点调整路径。

右侧「属性」可编辑节点填充色、透明度、边框、虚线、圆角和阴影；边可编辑线条颜色、宽度、透明度、线型、起始箭头、结束箭头、连接类型和标签文本。多选值不一致时显示「多个值」，一次控件提交统一更新全部适用目标并形成一条撤销记录。

## 文本与样式

双击节点，或单选节点后按 F2/Enter，打开就地文字编辑；双击连线编辑首个标签。失焦或 Ctrl/Cmd+Enter 提交，Esc 取消，普通 Enter 在文字内换行。中文输入法组合期间不会产生中间历史，组合完成后再提交。

紧凑工具栏和右侧「属性」可设置字体、字号、粗体、斜体、下划线、删除线、文字颜色、背景色、水平/垂直对齐、横排/竖排、四边距、段前、段后和行距。竖排按字符逐行排列，不旋转整段文本。单段超过 10000 字符时会提示「文本长度超出限制。」且不提交。

「格式刷」要求恰好选择一个源图元。单击刷一次，双击保持连续模式；点击目标应用，Esc 或点击画布空白退出。它复制节点/边样式和文本格式，不复制位置、尺寸、旋转、文字内容、图片、链接、端口、业务数据、形状类型或容器关系。

## 排列、组合与容器

「工具」菜单和多选右键提供「对齐」「分布」「自动连线」；「格式」菜单提供「置于顶层」「置于底层」「上移一层」「下移一层」「组合」「取消组合」。对齐至少选择两个节点，并以选择序列第一个节点为锚；分布至少选择三个节点，固定两端并让相邻边界间距相等；空间不足时会提示「间距不足，无法等距排列。」。

「自动连线」按选择顺序连接相邻节点，一次撤销删除本次生成的全部连线。组合会创建包含成员的组合节点，成员 ID 与数据保持不变；移动容器时成员一起移动。右键「加入容器」「添加成员」「取消组合或移出容器」管理归属，不允许形成父子循环。

## 查找替换

选择「工具」->「查找替换」打开右侧面板。输入查找文本，使用 `Aa` 区分大小写、`Ab|` 启用 Unicode 全词匹配，并选择「当前页」或「全部页面」。范围仅包括节点文字和连线标签，不包括页面名、链接或业务数据。「查找下一个」跨页循环并选中目标。

输入替换文本后可替换当前匹配。「全部替换」先显示命中数量和前 20 项预览，确认后整批只产生一条历史；按一次撤销可恢复全部原文。按 Esc 或「返回属性」退出查找模式。

## 链接

单选节点或连线，在右侧「属性」的「链接」输入框填写地址，失焦提交；留空可清除。只允许 http、https 和 mailto，其他协议提示「仅支持 http、https、mailto 链接。」。普通点击只选择图元，Ctrl（macOS 为 Cmd）+点击带链接节点才调用系统默认程序打开。

## 画布与视图

Ctrl（macOS 为 Cmd）+滚轮以光标为锚缩放；中键拖动或 Space+左键拖动平移。缩放范围 10%-400%，100% 等于 96 CSS px/in。「视图」菜单提供「适应屏幕」「适应页面」「适应内容」「适应选区」及「标尺」「网格」「参考线」「分页符」开关；状态栏可选择缩放比例并切换「网格」「对齐」。这些操作只改变视图，不进入撤销历史。

右侧面板可折叠；窗口较窄时变为右侧浮层，中央画布优先保留。主题、高对比和减少动态效果由「首选项」与系统偏好共同控制。

## 图层管理

选择「工具」->「图层管理」查看当前页节点和连线，列表按 zIndex 从高到低排列。选择条目会选中并居中对应图元；「置顶」「上移」「下移」「置底」各形成一条可撤销记录。领域模型没有图层隐藏字段，因此当前不提供可见性开关。

## 导出

选择「文件」->「导出」，设置「当前页」或「全部页面」、SVG/PNG/PDF/JSON、文件名和保存位置。PNG 额外选择 96、150 或 300 DPI；本次 DPI 不回写首选项。SVG 适合矢量编辑，PNG 是栅格图片，PDF 合并为按页面顺序排列的单文件，JSON 是可重新打开的 `.flowdiagram`。

全部页面导出为 SVG/PNG 时使用 `{文件名}-01-{页名}` 形式生成多个文件；PDF 和 JSON 各生成一个文件。SVG/PDF 只保留 http、https、mailto 安全链接。PDF 页面尺寸和链接注释是 pt 对象，但当前页面绘制内容为 72 pixels/in 栅格；需要矢量内容请选择 SVG。

目标选择取消、生成失败或磁盘写入失败都不修改文档、保存状态、撤销历史或 PNG 首选项，也不会留下部分新文件。导出执行中输入被锁定并显示「正在导出…」。

## 快捷键

| 快捷键 | 功能 |
|---|---|
| Ctrl/Cmd+N、O、S | 新建、打开、保存 |
| Ctrl/Cmd+Shift+S | 另存为 |
| Ctrl/Cmd+Z | 撤销 |
| Ctrl+Y；macOS Cmd+Shift+Z | 重做 |
| Ctrl/Cmd+X、C、V、D | 剪切、复制、粘贴、重复 |
| Ctrl/Cmd+A | 全选当前页 |
| Delete/Backspace | 删除选中图元 |
| Ctrl/Cmd++、Ctrl/Cmd+- | 放大、缩小 |
| F2 或 Enter | 编辑单个节点文字 |
| Esc | 取消文本/格式刷，关闭菜单、帮助或查找模式 |

输入框或文字编辑器聚焦时，画布删除和剪贴板快捷键不会抢占输入。完整列表可从「帮助」->「快捷键列表」查看。

## 首选项

选择「工具」->「首选项」设置主题、标尺、网格、参考线、分页符、默认缩放、单位、连接线、最近文件数量和 PNG DPI。点击「应用」后立即用于当前运行并写入本机；若持久化失败会显示提示，但本次运行仍使用新值。首选项不进入文档撤销历史。

## 错误排查

- 打不开图文件：确认扩展名为 `.flowdiagram`，文件为 UTF-8 JSON 且未手工破坏 ID、几何、端口、背景引用或链接。错误不会替换当前文档。
- 无法保存或导出：检查保存目录权限、磁盘空间、目标文件是否被占用，以及路径扩展名是否匹配格式。
- 图片导入失败：确认小于 5 MiB，格式为 PNG/JPEG/WebP，扩展名与真实内容一致；SVG 不支持。
- 粘贴出现降级提示：系统剪贴板权限或外部内容校验失败；先在应用内重新复制，再执行粘贴。
- 找不到文字：确认搜索范围、`Aa` 和 `Ab|` 状态；搜索不覆盖页面名、链接与业务数据。
- 形状无法对齐、分布、组合或自动连线：查看禁用项提示，确认节点数量、容器类型和选择顺序满足条件。

## 帮助

选择「帮助」->「帮助中心」「快捷键列表」或「关于」。页面设置、文本格式、格式刷、连线、形状库、组合容器和导出等复杂功能旁有 `?` 按钮；其提示与侧边帮助来自统一注册表，说明目的、操作方式、影响范围、撤销边界、限制和本文锚点。帮助可键盘访问，Esc 关闭，显示帮助不会修改文档或撤销历史。

## 关于

选择「帮助」->「关于」查看应用名称、版本和基本信息。当前版本不包含自动更新或许可管理。
