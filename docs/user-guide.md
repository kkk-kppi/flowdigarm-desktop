# 用户指南

> 本文档随实现更新：当前仅建立章节骨架，操作说明在对应功能任务落地后补全。

## 快速上手（3 分钟流程）

实现后补全：启动应用 → 新建文档 → 从图元库拖入形状 → 连接形状 → 保存文件的最短路径。

## 文件

实现后补全：新建、打开、保存、另存为、最近文件、自动保存与异常恢复。

## 编辑

实现后补全：撤销/重做（见帮助注册表 undo/redo 条目）、复制/剪切/粘贴、删除、全选。

## 画布与视图

画布位于主窗口中央，顶部与左侧带标尺（默认显示）。缩放：Ctrl（macOS 为 Cmd）+ 鼠标滚轮，以光标为锚点；平移：中键拖动或 Space+左键拖动。视图菜单提供适应窗口/页面/内容/选择、标尺、网格、参考线、分页符开关（菜单入口在后续任务接线）。缩放范围 10%–400%；标尺刻度随页面单位（mm/cm/in/pt/px）与缩放自动调整。以上视图操作不进入撤销历史，无法用 Ctrl+Z 回退。

## 排列

实现后补全：对齐、等距分布、层序调整、组合与容器。

## 导出

实现后补全：导出 SVG/PNG/PDF/JSON，当前页与全部页面选项，DPI 选择。
