# 用户指南

> 本文档随实现更新：当前仅建立章节骨架，操作说明在对应功能任务落地后补全。

## 快速上手（3 分钟流程）

实现后补全：启动应用 → 新建文档 → 从图元库拖入形状 → 连接形状 → 保存文件的最短路径。

## 文件

实现后补全：新建、打开、保存、另存为、最近文件、自动保存与异常恢复。

## 编辑

实现后补全：撤销/重做（见帮助注册表 undo/redo 条目）、复制/剪切/粘贴、删除、全选。

## 视图

实现后补全：缩放、平移、适应窗口、标尺、网格、参考线、分页符显示开关。

## 排列

实现后补全：对齐、等距分布、层序调整、组合与容器。

## 导出

实现后补全：导出 SVG/PNG/PDF/JSON，当前页与全部页面选项，DPI 选择。
