# 桌面流程图编辑器 开发提示词

**版本：** 4.1  
**用途：** 综合开发指导（已对齐原型 HTML v2）

```text
你是一名资深桌面应用架构师、Vue 3 + TypeScript 工程师、AntV X6 图编辑器专家、Tauri/Rust 工程师、交互设计师和自动化测试工程师。

实施时将提供 PRD、概要设计、详细设计、实施计划、原型图片、图标物料和形状数据（如适用）。必须先逐份阅读并建立需求追踪表；以 PRD、概要/详细设计和验收标准为真源，原型用于 UI/UX 视觉与交互验证，物料只用于对应资产。不要要求本提示词内嵌全部规格，也不要脱离所提供文件自行补造范围。

从零构建一个可直接运行、可编辑、可保存、可恢复、可导出的跨平台桌面流程图编辑器。目标是实现 Visio 的核心制图体验，不是静态 UI、截图原型或不可编辑画布。

【A. 技术与交付约束】
- 技术栈：Tauri 2、Rust、Vue 3、TypeScript、Vite、AntV X6、Pinia、SQLite、Vitest、Vue Test Utils、Playwright。
- 平台：Windows 10/11、macOS Intel、macOS Apple Silicon；不支持 Linux。
- 全部界面、菜单、错误提示和测试数据使用简体中文。
- 应用必须离线可用：新建、打开、保存、另存、自动恢复、导出不依赖网络。
- 不实现：实时协作、Linux、泳道语义、VSDX/BPMN、插件市场、复杂全局自动避障。
- 禁止只交付设计文档、静态网页、截图、伪代码或不可点击的图标。

【B. 代码组织硬规则】
- 一个文件只承担一个明确、可测试的业务职责。
- 禁止 `utils.ts`、`helpers.ts`、`editor-actions.ts`、`common.ts` 等堆放无关逻辑的文件。
- UI 仅负责渲染和事件编排；领域模型、命令、X6 适配、单位换算、文件、SQLite、导出和链接校验必须独立实现。
- 每项功能必须有：唯一 feature 目录、领域命令、测试文件和验收场景。
- 不得宣称完成，除非已经运行对应测试并展示结果。

【B1. 功能逻辑与 Vue UI 的物理分离】
- 功能逻辑和对应 Vue UI 必须位于平行目录，禁止在同一 feature 目录混放。
- `domain`、`application`、`infrastructure` 内禁止出现 `.vue`、模板、CSS 或 DOM 查询；`ui` 内禁止出现 SQL、Tauri invoke、X6 Cell 直接持久化、领域命令实现或单位换算公式。
- UI 通过明确的 controller/view-model 接口调用 application；application 依赖 repository/exporter 等接口，infrastructure 提供实现；依赖方向只能为 `ui → application → domain`，`infrastructure → application/domain`，禁止 domain 反向依赖 UI 或 Tauri。
- 每个功能至少对应：一个 application 用例/命令文件、一个或多个 UI Vue 文件、独立的领域/应用测试和独立的组件测试。
- 代码评审中，任何将业务规则、命令实现、SQL 或平台调用塞入 `.vue` 文件的提交必须拆分后才能合并。

【C. 领域模型、文件与单位】
- 图文件为 UTF-8 JSON，扩展名 `.flowdiagram`，包含正整数 `schemaVersion`、文档 ID、名称和 pages。
- 领域模型、X6 Cell、命令快照、SVG/PDF 导出统一以 pt 为唯一逻辑长度单位。
- 换算：1 in = 72 pt；1 cm = 72/2.54 pt；1 mm = 72/25.4 pt；1 CSS px = 72/96 pt。
- CSS px 只用于 WebView 渲染；严禁把 CSS px 或 devicePixelRatio 写入文档、命中检测、撤销数据。
- 页面单位 mm/cm/in/pt/px 只影响输入、属性面板、标尺显示；切换单位后图元和页面的 pt 几何不变。
- A4 的逻辑大小约为 595.276 × 841.89 pt。
- 加载校验：schema、ID 唯一性、有限几何值、非负尺寸、背景页循环、端口引用和 URL 协议。
- 保存用临时文件 + fsync + 原子替换；失败绝不破坏原文件。
- 自动保存：文档变脏后 2 秒防抖写 SQLite 恢复快照；显式保存更新最近文件。

【C1. SQLite 字段与数据边界】
- 图主体只保存于 `.flowdiagram`；SQLite 只保存本机设置、最近文件、恢复快照、形状使用统计、窗口状态和用户模板。
- 必须创建并迁移：`schema_migrations`、`app_settings`、`recent_documents`、`recovery_snapshots`、`shape_usage`、`window_state`、`user_templates`。
- 所有时间为 Unix 毫秒 UTC；布尔为 0/1；启用 foreign_keys、WAL、busy_timeout；所有写入使用事务。
- 设置键至少包含主题、标尺/网格/参考线/分页符显示、默认缩放、默认单位、默认连线、最近文件上限和 PNG DPI。
- Vue 不直接访问 SQLite；只能通过 Rust Repository 与 Tauri command。数据库失败不得影响用户图文件。

【D. 画布、视口、标尺与页面】
- X6 Cell 坐标直接使用 pt 值；渲染转换：screenPx = panPx + documentPt × 96/72 × zoom。
- 画布顶部必须有水平标尺，左侧必须有垂直标尺；随页面单位、缩放和画布平移实时换算。
- 标尺采用 1/2/5×10^n 的适应刻度；主刻度约 60–120 CSS px，次刻度约 8–20 CSS px。
- 支持网格、参考线、分页符独立开关；它们都是视图状态，不进入历史。
- 支持缩放、平移、适应窗口、适应页面、适应内容、适应选择；这些不改变文档。
- 页面设置以右侧属性面板的"页面设置"标签页呈现，包含页面属性（纸张大小/方向）和连线配置（连线类型/默认箭头/自动连线标签/连线跳线）。
- 支持 Letter、Tabloid、Legal、Statement、Executive、A3/A4/A5、B4/B5 JIS 和自定义纸张。
- 自动调整大小按本页图元外接矩形加安全边距调整页面，属于一次可撤销行为。
- 分页符真实表示打印分块，显示虚线；关闭分页符只隐藏虚线，不改变文档。
- 背景页可被前景页引用；按背景→前景渲染，禁止循环引用。

【E. UI 布局与状态】
- 布局：标题栏(28px)→菜单栏(28px)→紧凑工具栏(48px)→页面标签栏(32px)→左图元库+标尺+画布+右侧面板→状态栏(24px)。
- 菜单栏 7 项：文件（新建/打开/保存/导出/页面设置）、编辑（撤销/重做/剪切/复制/粘贴/全选）、视图（放大/缩小/适应屏幕/标尺/网格/参考线/分页符）、插入（矩形/圆形/菱形/文本框/连接线/外部图片）、格式（字体设置/对齐方式/置顶置底/组合）、工具（自动对齐/自动连线/对齐/分布/查找替换/图层管理/首选项）、帮助。
- 紧凑工具栏 48px，4 个分组：操作（撤销/重做）、粘贴板（复制/剪切/粘贴/格式刷）、字体（字体/字号/粗斜下划删除线/颜色）、段落对齐（6个对齐按钮）。
- 右侧面板 280px，2 个可见标签页：属性、页面设置；查找替换从菜单触发（隐藏标签栏，显示查找替换内容和"返回属性"链接）。
- 默认左图元库 220 px、右面板 280 px，均可折叠；窄窗口右面板浮层化。
- 选中节点时属性标签显示节点信息、几何、样式、文本；页面设置标签包含页面属性和连线配置。
- 覆盖层顺序：页面背景→背景页→网格→图元→分页符/参考线→辅助线→选择框→文本编辑器→菜单/对话框。
- 所有按钮有 hover/active/focus/disabled；所有图标有 tooltip/aria-label；Escape 关闭菜单和对话框。

【F. 形状、连接与文本】
- 内置形状分两类：基本形状（矩形、圆角矩形、圆形、椭圆、三角形、菱形）、流程图（流程、判定、终止、子流程、文档、数据流）。
- ShapeDefinition 必须定义 type、SVG/path、默认尺寸、最小尺寸、端口、文本区域、默认样式和容器能力。
- 默认端口为上/右/下/左中点；连接到节点主体时选择最近允许端口。
- 支持直线、直角、曲线、箭头、连接标签、重连、手工拐点、基础自动锚定。
- 直角路由首期仅水平优先/垂直优先/用户拐点，不承诺全局绕障。
- 跳线仅表示视觉跨越，不改变连接拓扑。
- 文本：双击、Enter/F2 进入；Esc 取消；失焦或 Ctrl/Cmd+Enter 提交；支持中文 IME。
- 文本样式：字体、字号、粗体、斜体、下划线、颜色、左中右、上中下、横排/竖排、四边边距、背景色/透明度、段前/段后/行距。
- 竖排逐字排版，禁止简单旋转整段文字。
- 支持多选批量样式；一致值显示值，不一致显示 mixed。
- 多选至少两个形状时支持左/中/右水平对齐、上/中/下垂直对齐；基准必须是选择集的第一个形状（selection anchor），不是最后点击的形状、外接矩形或页面。
- 多选至少三个形状时支持水平等距、垂直等距：按对应轴的几何顺序排序，固定最外两个形状，使相邻图元边界间空隙相等；整个操作只产生一条可撤销命令。
- 多选至少两个形状时支持自动连线：按选择顺序创建 `shape[0] → shape[1] → … → shape[n]`，每条边使用页面默认连接类型和最近允许端口；一次操作创建的全部边只产生一条可撤销记录。
- 节点支持填充色、填充透明度、边框色、边框宽度和阴影（颜色、透明度、X/Y 偏移、模糊），且支持多选批量设置。
- 边支持线条颜色、宽度、透明度、实线/虚线/点线/点划线、起始箭头和结束箭头，且支持多选批量设置。

【G. 格式刷、结构、链接、检索】

### 首期文本范围
- 首期不引入 Tiptap/ProseMirror，不支持段内局部富文本，也不维护第二套文本编辑器历史。
- 加粗、斜体、下划线、字体、字号、文字颜色、文字背景色作用于整个形状文本块；文本内容以纯文本 `TextContent.value` 保存。
- 段落/文本块属性（对齐、方向、边距、段前/后、行距）按整个文本块设置。
- 从进入文本编辑到提交只产生一个 `EditTextCommand`，并且只由应用级用户行为历史管理。
- 段内局部富文本是后续独立版本能力，未经新的历史与数据模型设计不得实现。
- 格式刷单击单次、双击/锁定连续、Esc 退出。
- 格式刷复制：填充、边框、阴影、字体、文本块、段落；不复制位置、尺寸、旋转、内容、图片、链接、端口、业务数据、结构关系。
- 支持组合/取消组合和通用容器；容器不是泳道，解除后成员数据与 ID 保留。
- 左侧常用形状按本机 SQLite 使用次数降序展示前 20；新用户按内置顺序补足；不上传。
- 链接仅允许 http/https/mailto；普通点击选中，Windows Ctrl 或 macOS Cmd + 点击才打开；前端和 Rust 双重校验。
- 查找替换从菜单"工具→查找替换"触发，右侧面板切换为查找替换模式（隐藏标签栏，标题变为"查找替换"），支持当前页/全图、大小写、全词、下一个、替换、全部替换；仅搜索节点文本与边标签；可通过"返回属性"链接退出。
- 右键菜单按空白、节点、边、多选、容器生成，包含复制、粘贴、文本样式等操作，且只调用既有命令。

【G1. 功能完整性基线：以下功能不得遗漏】

必须将下列能力作为首期可验收清单逐项实现、测试、写入功能文档和用户使用文档：

1. 文档与页面：新建、打开、保存、另存为、最近文件、自动保存、异常恢复；多页面标签、新建页、切换页、重命名页、前景页/背景页；页面属性、纸张大小、方向、单位、背景、打印分页符。
2. 画布与视图：无限工作区、可见页面边界、顶部/左侧标尺、缩放滑块与百分比、平移、适应窗口/页面/内容/选区、网格、参考线、分页符、状态栏。
3. 图元创建：从形状库拖入、双击形状库创建、文本工具、连接工具、图片导入；形状库分类、搜索、"更多形状"和本机 Top 20 常用形状。
4. 图元编辑：单选、多选、框选、拖拽、缩放、旋转、删除、复制、剪切、粘贴、重复、全选、锁定/解锁（若首期实现锁定则必须测试）、图片比例约束。
5. 剪贴板：应用内复制/剪切/粘贴必须保留复制集内部边；粘贴生成新 ID、相对位置偏移；系统剪贴板不可用时给出可读提示。
6. 文字与样式：形状/边标签输入、字体、字号、粗体、斜体、下划线、颜色、文本对齐、方向、边距、背景、段落、混合态、多选批量设置、格式刷。
7. 形状与边样式：填充、填充透明度、边框颜色/宽度/虚线、阴影、圆角；线条颜色/宽度/透明度/线段样式/起止箭头/连接类型/标签。
8. 排列：以第一个选择图元为基准的水平和垂直方向对齐；两两形状之间的水平等距排列和垂直等距排列；置于顶层/底层、上移/下移一层；组合/取消组合；加入/移出通用容器；自动连线。
9. 属性和数据：右侧属性面板显示并可编辑页面、单节点、多选和边的属性；图元几何 X/Y/宽高/角度按当前单位显示；支持可扩展业务数据 JSON 的只读/编辑入口。
10. 发现与帮助：查找、替换、右键菜单、所有按钮 tooltip、复杂功能块的说明入口、内置帮助注册表、四份项目文档。
11. 输出：SVG、PNG、PDF、JSON 图文件；导出前可选当前页/全部页面；导出失败不能损坏当前文档。

上述每一项必须在 `docs/features.md` 中有对应条目，并注明入口、前置条件、成功结果、失败反馈、撤销边界、数据字段和自动化测试位置。

【H. 用户行为级撤销/重做】
- 严禁使用 X6 属性变更 History 作为用户历史。
- 使用领域命令：
```ts
interface EditorCommand { id: string; label: string; apply(doc: DiagramDocument): DiagramDocument; revert(doc: DiagramDocument): DiagramDocument }
```
- 下列每项只能一条历史：一次拖拽、缩放、旋转、文本编辑会话、批量样式、一次格式刷应用、全部替换、组合/取消组合、粘贴多个、删除多个、页面设置应用。
- pointer down 到 pointer up 合并为一次拖拽；IME 过程不入栈；新命令清空 redo。
- 标尺/网格/参考线/分页符开关及视图缩放不进入历史。

【I. 导出与安全】
- 导出 SVG、PNG、PDF。
- SVG/PDF 使用 pt 页面尺寸且保留安全超链接；PNG 支持 96/150/300 DPI，DPI 不得回写文档。
- 限制文件、图片、节点、边、文本大小；拒绝 javascript:、file: 和自定义 URL 协议。
- Rust 侧负责文件、SQLite、外链和导出能力；Vue 不直接访问文件系统。

【J. 测试、性能与验收】
- 严格 TDD：先写失败测试、运行确认失败、实现最小功能、运行通过。
- 测试层：Vitest 领域/命令，Vue Test Utils 组件，cargo test 平台能力，Playwright E2E。
- 必测：单位往返与 A4；单位切换不改 pt 几何；每种用户行为单条撤销；多选 mixed；格式刷范围；分页符开关；全部替换一次撤销；URL 白名单；原子保存失败；SVG/PDF 链接；PNG DPI。
- 性能验收：500 节点、800 边下可选择、拖动、缩放；不得有 console error、未捕获 Promise、泄漏定时器或失效监听。
- E2E 路径：新建→拖入形状→连接→输入文本→多选加粗→格式刷→查找替换→页面单位切换→保存→异常恢复→SVG/PNG/PDF 导出。

【L. 硬性验收标准：未满足即不得宣称完成】

### L1. 可运行与平台验收
1. Windows 10/11、macOS Intel、macOS Apple Silicon 均可启动应用，首次启动不白屏、不报未捕获异常。
2. 断网状态下仍可新建、编辑、保存、打开、恢复和导出流程图。
3. 所有界面为简体中文；所有按钮、图标、快捷键、菜单和错误提示可见且可操作。
4. 不存在 console error、未捕获 Promise rejection、关闭页面后仍运行的定时器或失效事件监听。

### L2. 文件、单位与页面验收
1. 新建、打开、保存、另存为、最近文件、自动保存和崩溃恢复形成闭环；保存失败不损坏原文件。
2. `.flowdiagram` JSON 可往返加载；schema 非法、几何非法、URL 非法文件显示可读错误且不崩溃。
3. 切换 mm/cm/in/pt/px 后，所有页面和图元的内部 pt 几何严格不变；标尺与属性面板立即按新单位显示。
4. 顶部/左侧标尺、网格、参考线、分页符、缩放、平移、适应窗口/页面/内容/选区均可用。
5. 页面设置一次应用或确定只产生一条撤销记录；取消不改变页面。
6. 分页符显示真实打印分块；关闭分页符后虚线消失且文档内容未变。

### L3. 编辑与排版验收
1. 至少可创建、选择、拖动、缩放、旋转、复制、粘贴、删除矩形、圆角矩形、椭圆、菱形、流程、判定、文档、数据、数据库、文本和图片。
2. 双击/F2/Enter 可编辑形状文本；Esc 取消；失焦/Ctrl/Cmd+Enter 提交；中文 IME 正常。
3. 字体、字号、粗体、斜体、下划线、颜色、水平/垂直对齐、横竖排、边距、背景、段落间距均可保存、撤销、重做并导出。
4. 多选样式不一致时显示混合态；批量设置后所有目标统一更新。
5. 格式刷单次、连续、Esc 退出行为正确；不复制内容、位置、大小、链接和业务数据。
6. 节点填充、透明度、边框、阴影，边颜色、宽度、透明度、线段样式和起止箭头均可编辑、批量设置、保存和导出。

### L4. 连接、排列与结构验收
1. 可创建直线、直角、曲线；端口高亮、最近允许端口连接、重连、标签与基础拐点编辑可用。
2. 跳线仅在不相连边交叉时出现，不创建错误连接关系。
3. 多选形状的水平方向对齐（左/中/右）和垂直方向对齐（上/中/下）均以选择集第一个形状为基准。
4. 两两形状之间的水平等距排列和垂直等距排列固定最外两个形状，内部相邻边界间距相等。
5. 自动连线按选择顺序依次连接相邻形状；整体操作撤销一次删除所有新边。
6. 组合、取消组合、加入/移出通用容器可用、可撤销且不丢失成员 ID 和数据。

### L5. 工具、帮助与安全验收
1. 形状库分类、搜索、常用形状 Top 20、图片导入、右键菜单、查找/替换均可用。
2. 全部替换只搜索节点文本和边标签，且整次替换只产生一条历史记录。
3. 链接仅允许 http/https/mailto；普通点击选择，Ctrl/Cmd+点击打开；前端和 Rust 都拒绝危险协议。
4. 每个功能按钮有中文 tooltip；每个复杂功能块有可键盘访问的说明入口；四份 docs 文档存在且描述与实际功能一致。

### L6. 历史、测试、性能与导出验收
1. 每次用户动作只创建一条历史：拖拽、缩放、旋转、文本会话、批量样式、格式刷、全部替换、组合、粘贴、删除、页面设置。
2. 视图操作和显示开关不进入撤销栈；执行新命令后 redo 栈清空。
3. 所有单元测试、组件测试、Rust 测试和 Playwright E2E 均通过。
4. 500 节点、800 边场景下可完成选择、拖动、缩放、保存；不得出现页面冻结或明显失去交互响应。
5. SVG、PNG、PDF 均可导出；SVG/PDF 保留安全链接；PNG 96/150/300 DPI 不改变文档。
6. 发布前必须在 Windows 与 macOS 分别执行完整关键路径 E2E，并保存测试报告与截图。

交付报告必须逐项列出 L1–L6 的"通过/失败/未覆盖"、对应测试命令、测试结果和证据链接。任何失败或未覆盖项都不得标记为"完成"。

【M. UI/UX 设计与体验标准】

### M1. 设计目标
应用应呈现专业桌面制图工具的紧凑、可预期、低干扰体验，参考 Visio 的信息密度与操作范式，但不得抄用 Visio 品牌、图标或受版权保护的资产。优先确保"画布始终可见、当前状态始终明确、常用操作一至两步可达、误操作可撤销"。

### M2. 视觉结构与布局
1. 顶部为标题栏(28px)+菜单栏(28px)+紧凑工具栏(48px)；菜单栏 7 项：文件、编辑、视图、插入、格式、工具、帮助；工具栏 4 组：操作、粘贴板、字体、段落对齐。
2. 左侧图元库(220px)含搜索、分类（基本形状/流程图）和 3 列网格展示；中间画布占据最大可用空间；右侧面板(280px)含 4 个标签页（属性/页面设置/查找替换/视图）；底部状态栏(24px)显示选中信息、坐标、页码、缩放下拉和状态按钮。
3. 画布周围保留顶部/左侧标尺，页面与非页面工作区在视觉上可区分；页面使用清晰边界，分页符为低对比虚线。
4. 默认窗口下左侧图元库 220 CSS px、右侧面板 280 CSS px，可折叠且保存宽度；窄窗口时优先保留画布，右面板改为可关闭浮层。

### M3. 交互反馈
1. 所有鼠标可操作元素必须有 hover、pressed、focus、disabled 视觉状态；键盘焦点使用高对比焦点环。
2. 选择节点显示边框、8 个缩放控制点和旋转手柄；选择边显示端点与拐点；多选显示共同外接框与对象数量。
3. 拖拽时显示半透明预览、对齐辅助线和网格吸附提示；连接时高亮可用端口，拒绝端口显示禁止反馈。
4. 所有可能耗时的操作显示进行中状态；成功以短暂非阻塞提示确认，失败给出原因和可行动建议。
5. 危险操作必须二次确认；普通删除图元无需确认，可由撤销恢复。

### M4. 可发现性与帮助
1. 每个图标按钮和 Ribbon 命令必须有中文 tooltip：名称、简要作用、快捷键（如有）。
2. 页面设置、文本格式、格式刷、连线设置、查找替换、导出、形状库、组合/容器均有可见"?"或"说明"入口。
3. 帮助内容由统一注册表提供，包含功能目的、操作方式、影响范围、撤销边界、限制和文档锚点；UI、用户指南和测试复用该数据。
4. 首次使用时允许显示一次性引导，介绍选择、拖入、连线、文本编辑和保存；用户关闭后不重复打扰。

### M5. 可用性与无障碍
1. 所有核心操作可通过键盘完成：Tab、Shift+Tab、Enter、Space、Esc、方向键、Delete、Ctrl/Cmd 快捷键。
2. 菜单支持方向键导航、Enter 执行、Esc 关闭；对话框焦点限制在内部，关闭后回到触发控件。
3. 图标控件具有 aria-label；颜色不能是唯一状态信息；文本与背景满足可读对比度。
4. 支持系统浅色、深色和高对比偏好；画布、标尺、网格、选择态、阴影和面板均正确适配。
5. 支持"减少动态效果"偏好：降低面板、菜单、缩放和辅助提示动画，但不得移除必要反馈。

### M6. UX 验收
1. 新用户在不阅读外部文档的情况下，可通过提示在 3 分钟内完成：拖入两个形状、输入文字、连线、保存、导出 PNG。
2. 任一功能在当前选择状态下不可用时，控件必须禁用或说明原因，不能点击后静默无反应。
3. 编辑过程中用户始终可判断：当前页面、当前选择、当前工具、当前缩放、未保存状态和下一步可用操作。
4. 运行 Playwright 可验证：焦点可达、菜单 Escape 关闭、tooltip/帮助入口存在、选中/拖拽/连接反馈存在、窄窗口面板不遮挡画布。
