# 编辑器布局原型对齐设计

## 目标

在不改变画布、产品默认状态和编辑功能的前提下，修正当前编辑器外壳与产品原型之间已确认的四项布局偏差：页签层级、重复缩放控件、图元分类标题样式和属性面板分组布局。

## 范围

### 包含

- 页签栏仅覆盖中央画布，不再横跨左右侧栏。
- 删除页签栏中的缩放滑块和百分比，缩放入口仅保留在状态栏。
- 图元库分类标题改为整行浅灰背景，图元网格仍保留内部留白。
- 属性面板改为无卡片分组、水平分隔线和几何字段两列布局。
- 保留属性面板现有全部字段、顺序和行为。

### 不包含

- 不修改 X6 画布、页面边界、页面阴影或工作区背景。
- 不修改初始缩放、自动适应页面、网格和吸附默认状态。
- 不修改工具栏按钮形态、标题栏或菜单栏。
- 不删除、隐藏或迁移链接、业务数据、透明度、边框宽度等现有属性。
- 不修改图元库“常用”区、搜索、拖拽、折叠和更多形状功能。

## 结构设计

`AppShell` 继续负责编辑器外壳，但三栏主体调整为以下结构：

```text
TitleBar
MenuBar
CompactToolbar
shell-main
├── ElementLibrary
├── canvas-column
│   ├── PageTabs
│   └── CanvasArea
└── RightPanel
StatusBar
```

新增的 `canvas-column` 是可收缩的纵向 flex 容器。它占据左右固定栏之间的剩余宽度，并设置 `min-width: 0`、`min-height: 0`，避免画布或页签内容撑破外壳。`CanvasArea` 继续填充中央列剩余高度。

图层管理面板继续作为 `shell-main` 的现有附加子项，不改变其打开、关闭或尺寸行为。

## 页签与缩放

`PageTabs` 只负责页面切换、重命名、删除和新增页面。删除以下内容：

- 页签栏右侧缩放滑块和百分比。
- 为该控件维护的 `zoomPercent` 状态。
- 对页面视口控制器的订阅和清理逻辑。
- `onZoomInput` 及对应样式。

底部 `StatusBar` 的缩放选择器、`AppShell.onSetZoom` 和 `CanvasArea` 缩放接口保持不变，确保缩放功能仍有唯一入口。

## 图元库分类

图元库滚动内容区取消统一的左右内边距，使 `.category-header` 能铺满可用宽度。分类标题采用原型浅灰背景，并保留当前字体、展开箭头和点击区域。

图元缩略图网格单独增加左右内边距，维持当前三列布局和图元间距。“无匹配图元”提示也保留合理的水平留白。该变化应用于“常用”“基本形状”和“流程图”的所有分类标题。

## 属性面板

### 分组样式

现有 `.prop-section` 不再绘制完整边框、圆角或裁剪内容。各分组以水平分隔线区分；标题使用白色/透明背景，弱化卡片感。展开折叠按钮、ARIA 状态和现有条件渲染保持不变。

### 几何布局

几何分组的四个字段按当前 `geometryFields` 顺序排列为两列网格：

```text
X    Y
宽   高
```

每个字段内部仍由标签、单位和数值输入框组成，继续调用现有 `geometryDisplay` 与 `commitGeometry`，不改变单位换算、提交时机或命令历史。

### 现有字段

节点信息、链接、业务数据、样式、文本、连线等现有分组和字段全部保留。此次只修改视觉分组和几何排版，不重排业务功能。

## 响应式与无障碍

- 左右面板现有折叠逻辑保持不变。
- 右侧面板在窄窗口下的浮层逻辑保持不变。
- DOM 顺序与视觉顺序一致：左栏、中央工作区、右栏。
- 删除重复缩放控件后，状态栏缩放选择器保留原有标签、键盘操作和焦点行为。
- 分类标题与属性分组继续使用原有原生按钮，不改变键盘和屏幕阅读器语义。

## 测试与验收

- 组件测试验证 `PageTabs` 位于中央列中，左右侧栏不位于页签栏下方。
- `PageTabs` 测试验证不再渲染 `zoom-slider` 和 `zoom-percent`，页面新增、切换、重命名和删除仍通过。
- `StatusBar` 测试验证缩放选项及 `setZoom` 事件保持可用。
- `ElementLibrary` 测试验证所有分类标题仍可展开折叠，图元创建、搜索和拖拽相关行为不变。
- `PropertyTab` 测试验证几何容器使用两列结构，四个字段和提交行为保持不变；额外属性字段仍存在。
- 在 Chromium 中检查三栏顶边对齐、页签仅覆盖画布、分类标题整行灰底、属性分隔线和几何两列的实际边界。
- 运行相关组件测试、完整 `pnpm test`、`pnpm build` 和 `git diff --check`。

## 验收标准

- 工具栏下方同一水平线上分别出现图元栏标题、中央页签栏和属性栏标题。
- 页签栏宽度随中央画布变化，不覆盖左右侧栏。
- 顶部不再出现缩放控件，底部状态栏缩放功能正常。
- 图元分类标题浅灰背景从左边界延伸到右边界，图元网格仍有内边距。
- 属性分组没有圆角卡片外框，分组之间使用水平线；几何字段为两列。
- 所有明确列为非目标的功能和默认状态保持不变。
