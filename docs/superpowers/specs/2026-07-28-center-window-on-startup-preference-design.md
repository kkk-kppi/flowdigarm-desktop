# “应用启动居中”首选项设计

## 目标

在现有自适应窗口尺寸与状态恢复能力上增加可选的“应用启动居中”行为。用户可以让应用每次启动时在上次使用的显示器工作区内居中，同时保留上次普通窗口尺寸和最大化状态。

## 用户界面

在“首选项”对话框新增“窗口”分组，其中包含一个复选框：

- 名称：**应用启动居中**
- 内联说明：**下次打开应用时，窗口会显示在上次使用的屏幕中央。窗口大小和最大化状态保持不变。**

说明文本始终显示在设置名称下方，并通过 `aria-describedby` 与复选框关联。关键说明不依赖鼠标悬停；Tooltip 只能作为补充。

点击“应用”只保存设置，不立即移动当前窗口。点击“恢复默认”将开关恢复为关闭。

## 首选项说明约定

本功能同时确立后续首选项文案约定：

- 含义和影响直观的设置可以只显示名称。
- 生效时机、作用范围、数据影响或副作用不直观的设置必须提供名称下方的内联说明。
- 说明优先回答“做什么、何时生效、保留或改变什么”。
- Tooltip 不能代替影响用户决策的关键说明。
- 本次只为新增设置应用该结构，不顺带重构现有首选项。

## 设置模型

- 前端字段：`EditorPreferences.centerOnStartup: boolean`。
- SQLite 设置键：`window.centerOnStartup`。
- 默认值：`false`。
- 唯一事实源：现有 SQLite `app_settings`。
- 不修改 `window_state` 表，不增加数据库迁移、插件或额外状态文件。

前端 `SettingsController` 负责该字段的默认值、布尔校验、加载和保存。Rust 启动流程从同一 `app_settings` 键读取设置，确保窗口显示前已经决定启动位置。

设置缺失、数据库不可用、读取失败或 JSON 不是布尔值时，Rust 安全回退为 `false`，继续使用当前的窗口位置恢复行为。

## 启动行为

### 开关关闭

保持现有行为：恢复上次普通窗口物理位置、逻辑尺寸和最大化状态。

### 开关开启

1. 根据保存的物理坐标识别上次所在显示器。
2. 恢复并按当前工作区夹取上次普通窗口逻辑尺寸。
3. 忽略保存的窗口坐标，将普通窗口在目标显示器可用工作区内水平和垂直居中。
4. 恢复上次最大化状态；最大化前的普通窗口边界为上述居中结果。

开关只改变启动位置，不改变保存逻辑。应用仍保存用户关闭前的真实窗口位置，因此用户以后关闭该开关时，可以继续恢复真实保存坐标。

### 无状态或异常状态

- 没有保存窗口状态时，无论开关是否开启，都执行现有首次自适应居中布局。
- 上次显示器已断开、保存状态损坏或窗口达不到 `64 x 40` 逻辑像素可见阈值时，回退到主显示器的首次自适应居中布局。
- 多显示器和混合 DPI 下继续使用现有 source-owner 与工作区选择规则；开关开启时在选定目标工作区内居中。

## 架构边界

- `src/application/settings/settings-controller.ts`：定义、校验并持久化前端首选项字段。
- `src/ui/dialogs/PreferencesDialog.vue`：呈现开关、内联说明和无障碍关联。
- `src-tauri/src/window_state.rs`：读取 Rust 侧设置并在纯几何恢复层决定保留坐标或居中。
- `src-tauri/src/persistence/sqlite_repository.rs`：继续提供通用设置读取能力，不增加窗口开关专用表或重复状态。
- WebView 不参与初始定位，避免窗口显示后跳动。

## 错误处理

- 设置读取或解析失败不阻止窗口启动，也不改变现有安全 fallback。
- 设置保存失败时，将通用首选项通知调整为：“设置保存失败。本次更改可能已在当前运行生效，但不会在下次启动时保留。”启动居中只有成功持久化后才能在下次启动生效，当前运行不移动窗口。
- 窗口状态、显示器或原生 API 失败继续沿用现有安全默认窗口、无可靠状态时不持久化和始终尽力显示/聚焦的策略。

## 测试

- `SettingsController`：默认关闭、合法布尔读取、无效值回退、保存键和值、恢复默认。
- `PreferencesDialog`：窗口分组、复选框、精确名称、精确说明、`aria-describedby`、应用与恢复默认。
- Rust 设置读取：缺失、`true`、`false`、非法 JSON、非布尔 JSON、数据库不可用。
- 窗口几何：关闭时保留坐标；开启时只重算位置并保留尺寸和最大化状态。
- 多显示器：开启时居中到上次所在显示器，断连时回退主显示器。
- 混合 DPI 和超宽保存尺寸：继续正确夹取逻辑尺寸，再按目标物理工作区居中。
- 完整运行 Rust 测试、Vitest、生产构建、格式检查和 `git diff --check`。

## 验收标准

- 首选项显示“应用启动居中”及始终可见的内联说明。
- 新设置默认关闭，升级后的既有用户行为不变。
- 开关开启后，下一次启动保留上次普通尺寸和最大化状态，只在上次显示器工作区内重算居中位置。
- 设置应用时不立即移动当前窗口。
- 显示器断开、状态无效或设置读取失败时，窗口保持可见并使用已定义的安全回退。
- 关闭开关后，后续启动重新使用真实保存位置。
