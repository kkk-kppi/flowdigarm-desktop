# 桌面流程图编辑器 产品需求文档（PRD）

**版本：** 4.1  
**平台：** Windows 10/11、macOS（Intel/Apple Silicon）  
**定位：** 离线、专业、可扩展的 Visio 核心体验流程图工具。

> 本 PRD 是当前唯一有效的产品需求基线；桌面端、pt 坐标、领域命令历史与验收标准均以本 PRD 及配套设计文档为准。已对齐原型 HTML v2。

## 1. 产品概述与目标

### 1.1 产品目标

让用户无需联网即可创建、编辑、保存、恢复和导出流程图，并提供接近 Visio 的页面、形状、连线、文本、样式、对齐、标尺与打印体验。

### 1.2 成功指标

- 新用户在 3 分钟内完成"创建两个形状→输入文字→连线→保存→导出 PNG"。
- 500 节点、800 边图中仍可选择、拖动、缩放和保存。
- 核心编辑动作均可一次撤销和重做。

## 2. 用户与场景

| 用户 | 场景 | 核心诉求 |
|---|---|---|
| 业务分析师 | 绘制流程、架构、说明图 | 快速成图、文字与样式易编辑 |
| 技术人员 | 绘制系统/数据流图 | 精确尺寸、连接、对齐、导出 |
| 文档作者 | 将图插入报告或演示 | 多页、纸张、PDF/SVG/PNG 输出 |

## 3. 功能范围

### 3.1 首期包含

- **文件**：新建、打开、保存、另存、最近文件、自动保存、崩溃恢复、`.flowdiagram`。
- **页面**：多页、前景/背景页、页面设置（右侧属性面板形式）、纸张/方向/单位、自动调整大小、分页符。
- **画布**：标尺、网格、参考线、缩放、平移、适应窗口/页面/内容/选择、状态栏。
- **图元**：基本形状（矩形、圆角矩形、圆形、椭圆、三角形、菱形）、流程图（流程、判定、终止、子流程、文档、数据流）、图片、文本框、容器、Top 20 常用形状。
- **编辑**：选择、多选、框选、拖动、缩放、旋转、复制粘贴、删除、分层、组合/容器。
- **文本**：输入、字体、样式、水平/垂直对齐、横竖排、边距、背景、段落、批量设置、格式刷。
- **连线**：端口、直线/直角/曲线、箭头、标签、跳线、自动连线、重连与拐点、自动连线
- **排列**：以第一个选择图元为基准的水平和垂直方向对齐；两两形状之间的水平等距排列和垂直等距排列
- **工具**：查找替换（右侧属性面板形式）、右键菜单（包含：复制、粘贴、文本样式）、超链接、帮助说明。
- **输出**：SVG、PNG、PDF、JSON（导出模态对话框）。

### 3.2 不包含

实时协作、Linux、泳道语义、VSDX/BPMN、插件市场、复杂全局自动避障。

## 4. 核心功能需求

### 4.1 页面与度量

页面设置以右侧属性面板形式提供，包含"页面属性"和"连线设置"两个标签页。单位支持 mm/cm/in/pt/px；切换仅改变显示与输入，内部几何不变。页面支持 A3/A4/A5、Letter 等预设和自定义尺寸。

### 4.2 图元与文本

双击、Enter/F2 编辑图元文本；Esc 取消，失焦或 Ctrl/Cmd+Enter 提交。多选样式不一致显示混合态。文本和图元样式可通过工具栏、属性面板与格式刷修改。

### 4.3 排列与连接

对齐以选择集第一个图元为锚点。等距排列固定两端图元，使中间图元间隙相等。自动连线按选择顺序连接相邻形状，整体为一次撤销操作。

### 4.4 撤销与可靠性

历史以用户行为而不是属性变化记录。一次拖拽、批量样式、格式刷应用、全部替换、页面设置、自动连线都只生成一条记录。保存采用原子替换，失败不损坏原文件。

### 4.5 查找替换

查找替换以右侧属性面板形式呈现，支持查找输入、替换输入、区分大小写、全词匹配、搜索范围（当前页/全部页面）选项，以及查找下一个、替换、全部替换操作。

### 4.6 导出

导出以模态对话框形式呈现，支持：
- **页面范围**：当前页 / 全部页面
- **文件格式**：SVG（矢量图，可缩放）、PNG（位图，适用于分享）、PDF（便携文档格式）
- **文件名**：可编辑
- **保存位置**：可浏览选择

SVG 导出将保留矢量质量和安全超链接。

## 5. UI 布局规格

### 5.1 整体布局

```text
┌ 标题栏 (28px) ─────────────────────────────────────────────────────┐
├ 菜单栏 (28px) ─────────────────────────────────────────────────────┤
├ 紧凑工具栏 (48px) ────────────────────────────────────────────────┤
├ 页面标签栏 (32px) ─────────────────────────────────────────────────┤
├ 图元 ┬ 水平标尺 ───────────────────────────────────┬ 属性/视图 ──┤
│(220px├ 垂直标尺 ┬ 画布 ──────────────────────────┤ (280px)      │
│      │          │                                │ 4个标签页     │
├──────┴──────────┴────────────────────────────────┴──────────────┤
│ 状态栏 (24px)                                                   │
└─────────────────────────────────────────────────────────────────┘
```

### 5.2 标题栏

高度 28px，包含：
- 应用图标（SVG）
- 应用名称："流程图编辑器"
- 当前文件名："未命名流程图.flowchart"
- 窗口控制按钮（全屏、最大化、最小化）

### 5.3 菜单栏

高度 28px，7 个菜单项：
1. **文件**：新建(Ctrl+N)、打开(Ctrl+O)、保存(Ctrl+S)、导出为图片、页面设置
2. **编辑**：撤销(Ctrl+Z)、重做(Ctrl+Y)、剪切(Ctrl+X)、复制(Ctrl+C)、粘贴(Ctrl+V)、全选(Ctrl+A)
3. **视图**：放大(Ctrl++)、缩小(Ctrl+-)、适应屏幕、标尺、网格、参考线、分页符
4. **插入**：矩形、圆形、菱形、文本框、连接线、外部图片
5. **格式**：字体设置、对齐方式、置于顶层/底层、组合/取消组合
6. **工具**：自动对齐、自动连线、对齐→（水平对齐/垂直对齐）、分布→（水平等距排列/垂直等距排列）、查找替换、图层管理、首选项
7. **帮助**：帮助中心、快捷键列表、关于

每个菜单项有 `?` 帮助图标。菜单项悬停展开下拉子菜单。

### 5.4 紧凑工具栏

高度 48px，单行紧凑布局，按分组组织控件：

| 分组 | 控件 |
|------|------|
| **操作** | 撤销、重做 |
| **粘贴板** | 复制、剪切、粘贴、格式刷 |
| **字体** | 字体选择下拉、字号选择下拉、粗体、斜体、下划线、删除线、文字颜色、文字背景色 |
| **段落对齐** | 顶端对齐、垂直居中、底端对齐、左对齐、居中、右对齐 |

分组之间用竖线分隔。视图控制（标尺/网格/参考线/分页符）、页面设置、查找替换功能放在右侧面板的对应标签页中。

### 5.6 页面标签栏

高度 32px，包含：
- 当前页面标签（可关闭）
- 添加页面按钮（+）
- 缩放控制（滑块 + 百分比显示）

### 5.7 左侧图元库

宽度 220px，可折叠，包含：
- **标题栏**："图元" + 折叠按钮
- **搜索框**：搜索图元
- **分类列表**（可折叠展开）：

| 分类 | 形状 |
|------|------|
| **基本形状** | 矩形、圆角矩形、圆形、椭圆、三角形、菱形 |
| **流程图** | 流程、判定、终止、子流程、文档、数据流 |

形状以 3 列网格展示，选中形状高亮。底部有"更多形状..."按钮。

### 5.8 画布区域

- **水平标尺**：顶部，高度 20px，显示刻度和单位
- **垂直标尺**：左侧，宽度 20px，显示刻度和单位
- **标尺交汇角**：左上角 20×20px
- **画布**：白色页面区域，显示网格点
- **页面边界**：清晰边框 + 阴影

### 5.9 右侧面板

宽度 280px，可折叠（左侧有折叠按钮），包含 2 个可见标签页 + 查找替换模式：

**属性标签页**（默认）：
- **节点信息**：类型（只读）、名称、ID（只读）
- **几何**：X、Y、宽、高
- **样式**：填充色、边框色
- **文本**：内容（多行文本框）、字体、字号、粗体/斜体/下划线/删除线、字体颜色、字体背景色、对齐方式（水平/垂直）

**页面设置标签页**：
- **页面属性**：纸张大小（A3/A4/A5/Letter）、方向（纵向/横向）
- **连线配置**：连线类型（直线/直角/曲线）、默认箭头（无/单向/双向）、自动连线标签开关、连线跳线开关

**查找替换模式**（从菜单"工具→查找替换"触发）：
- 隐藏标签栏，标题变为"查找替换"
- 查找内容输入框 + 查找按钮
- 替换为输入框 + 全部按钮
- "返回属性"链接可退出查找替换模式

### 5.10 状态栏

高度 24px，显示：
- **左侧**：选中信息（"已选择 N 个图元"）+ 坐标（X: xxx  Y: xxx）
- **右侧**：页码（"页 1/1"）、缩放控制（下拉菜单：50%/75%/100%/125%/150%/200%/适应屏幕）、网格状态按钮、对齐状态按钮、保存状态（绿色圆点 + "已保存"）

### 5.11 导出对话框

模态对话框，480px 宽，包含：
- **标题**："导出" + 帮助按钮 + 关闭按钮
- **页面范围**：当前页 / 全部页面（单选）
- **文件格式**：SVG / PNG / PDF（卡片式选择，选中高亮）
- **信息提示**：SVG 导出将保留矢量质量和安全超链接
- **文件名**：可编辑输入框 + 扩展名后缀
- **保存位置**：路径显示 + 浏览按钮
- **底部按钮**：取消、导出

## 6. 数据与技术约束

- **技术栈**：Tauri 2、Rust、Vue 3、TypeScript、X6、Pinia、SQLite。
- **坐标系统**：文档、X6 Cell、命令快照、SVG/PDF 均使用 pt；CSS px 仅渲染。
- **安全**：URL 仅允许 http/https/mailto，前端与 Rust 双重校验。
- **代码规范**：每个实现文件仅一个职责；领域、命令、UI、平台、导出独立分层。

## 8. 验收标准

1. Windows/macOS 可启动，离线可编辑与导出，无未捕获异常。
2. 单位切换不改变内部 pt 几何；标尺与属性正确变化。
3. 页面、图元、文本、连线、样式、格式刷、排列、自动连线、查找替换和超链接均可用、可保存、可撤销。
4. SVG/PDF 保留安全链接；PNG 以指定 DPI 导出。
5. 所有单元、组件、Rust 与关键 E2E 测试通过；500 节点/800 边可交互。
6. 交付报告逐项标记通过/失败/未覆盖；存在失败或未覆盖项不得标记完成。
