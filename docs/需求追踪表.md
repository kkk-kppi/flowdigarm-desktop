# 需求追踪表（需求 → 模块 → 文件 → 测试 → 验收）

**版本：** 1.0
**真源：** `产品需求文档.md`（PRD 4.1）、`概要设计.md`、`详细设计.md`；原型（`产品原型.html` / `产品原型-图片.png`）仅用于 UI/UX 视觉与交互验证。
**冲突裁决记录：**

1. 左侧图元库宽度/列数：详细设计 §6.3 的 320px/4 列与其 §18.5、PRD §5.7 及原型均冲突 → 以 PRD + 原型为准：**220px / 3 列**。
2. 右侧面板标签：以 PRD §5.9 与原型为准：**2 个可见标签页（属性/页面设置）+ 查找替换模式**（隐藏标签栏 + "返回属性"链接）。
3. 内置形状清单：以 PRD §3.1/§5.7 为准：基本形状 6（矩形/圆角矩形/圆形/椭圆/三角形/菱形）+ 流程图 6（流程/判定/终止/子流程/文档/数据流）+ 文本框 + 图片；验收 L3 中的"数据库"即"数据流"形状（圆柱图标）。
4. `.vue` 文件位置：B1 规则优先 → 所有 `.vue` 位于 `src/ui/`；`src/app/` 只放非 Vue 的应用级装配代码。
5. 详细设计 §18 编号重复（两个 18.5）不影响实现，以内容为准。
