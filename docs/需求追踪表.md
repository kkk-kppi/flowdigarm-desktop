# 需求追踪表（需求 -> 模块 -> 文件 -> 测试 -> 验收）

**版本：** 1.0

**真源：** `docs/产品需求文档.md`、`docs/概要设计.md`、`docs/详细设计.md`；原型仅用于视觉与交互核对。

**状态口径：** 「通过」表示对应自动化范围已实跑；「失败」表示已有反证；「未覆盖」表示未实现或没有足够实跑证据。平台整体状态以 `docs/acceptance.md` 为准。

## 冲突裁决

1. 左侧图元库采用 PRD 与原型的 220px/3 列，不采用详细设计中的 320px/4 列。
2. 右侧面板采用两个可见标签「属性」「页面设置」和独立「查找替换」模式，不伪造四个同时可见标签。
3. 内置注册形状为基本形状 6、流程图 6、文本框、图片，另有命令创建的组合形状；验收中的“数据库”按冲突记录对应圆柱「数据流」。
4. 所有 Vue 组件位于 `src/ui/`；应用装配、领域和基础设施按现有分层，不沿用早期设计中的 src/app 路径。
5. 节点 `data` 扩展字段、业务数据 JSON 对象校验、可撤销命令和属性面板入口均已实现；实现路径为 `src/application/inspector/business-data-json.ts`、`src/application/commands/set-business-data.ts`、`src/ui/inspector/PropertyTab.vue`，测试路径为 `tests/unit/editor/business-data-json.test.ts`、`tests/unit/editor/commands/set-business-data.test.ts`、`tests/component/PropertyTab.test.ts`。
