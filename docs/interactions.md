# 交互文档

本文记录当前桌面界面的鼠标、键盘、焦点和状态机规则。UI 标签以应用实际简体中文文案为准。

## 鼠标交互

### 视口与标尺

- **缩放**：按住 Ctrl（macOS 为 Cmd）滚动鼠标滚轮，以光标位置为锚点缩放（锚点下的文档 pt 在缩放前后保持不动）；缩放范围 10%–400%，100% 时 1 英寸 = 96 CSS px。
- **平移**：中键拖动，或按住 Space + 左键拖动；平移只改变视口，不修改文档。
- **适应视图**：「视图」菜单提供「适应屏幕」「适应页面」「适应内容」「适应选区」；页面/屏幕把整页适配视口，内容使用全部图元 bbox，选区使用选中图元 bbox。目标矩形居中，缩放钳制在 10%–400%；状态栏缩放下拉也提供「适应屏幕」。
- **标尺**：顶部水平与左侧垂直双标尺，随页面单位、缩放、平移实时换算；刻度 1/2/5×10ⁿ 自适应，主刻度约 60–120 CSS px、次刻度约 8–20 CSS px。
- 以上视图操作（缩放/平移/适应/标尺网格开关）均不进入撤销历史。

### 页面管理

- **切换页**：单击页面标签栏页签；切换为视图行为，不产生命令；每页拥有独立的撤销栈与视口状态，切回时恢复该页的缩放与平移。
- **重命名**：双击页签进入行内编辑，回车或失焦提交、Esc 取消；空白名称视为取消（不产生命令）。
- **删除**：页数大于 1 时页签显示 ×，点击弹出内联确认「删除此页？」，「确定」后删除（一条撤销记录）、「取消」保留；删除活动页时先切到存活页再删除，保证撤销可用；被引用为背景页的页面不能删除。
- **新建**：标签栏末尾 + 按钮新建「页面 N」（自动递增不重名）并切换过去。
- **背景页**：前景页渲染时先绘制其直接引用的背景页；背景页内容在前景页不可选择、不可交互，需切换到该背景页编辑。
- 切换页、分页符显示开关均不进入撤销历史；页面设置一次「应用」只产生一条记录。

### 选择与拖拽状态机

```text
Idle → PointerDown → 移动 ≥3px？ → Dragging → PointerUp → Idle
                └→（阈值内松开）按单击处理 ──────────────┘
```

- **拖拽阈值**：3 CSS px；阈值内松开按单击处理（单击选中图元、单击空白清空选择）。
- **框选**：空白处按下并拖动形成橡皮筋框选；Ctrl（macOS Cmd）+单击切换单个图元选中；选择序列保序，首元素为对齐锚点。
- **拖拽移动**：选中节点拖动时显示对齐辅助线；指针松开才创建一条「移动图元」记录。
- **缩放/旋转**：选中节点出现 Transform 手柄；缩放手柄遵循形状最小尺寸（文本框 24×20、图片 24×24、其余 36×24pt）；图片/椭圆按住 Shift 缩放保持纵横比；一次手势结束各产生一条记录。
- **连线**：悬停节点显示四边中点端口，从端口拖出连线；拖动中可用端口高亮（可连接/已吸附两档）；落到目标端口直接锚定，落到节点主体按落点距离自动选择最近端口（等距按上→右→下→左）；不允许自环、悬空端点与容器端点。
- **边编辑**：选中边显示拐点与两端箭头手柄；拖动端点重连（一条「重新连接」记录），拖动拐点调整路径（一条「编辑拐点」记录）。
- **跳线**：页面开启跳线后，非曲线连线在交叉处绘制小弧；跳线仅视觉跨越，不改变连接关系。
- **Esc**：回到选择工具（退出当前手势/模式）；格式刷模式下取消格式刷（见下文状态机）。
- 切换页自动清空选择；选择、框选、端口高亮均为交互状态，不进入撤销历史。

### 格式刷状态机

```text
off →（恰好 1 个选中图元 + 单击格式刷按钮）→ once →（点击目标图元，应用一条「格式刷」记录）→ off
off →（恰好 1 个选中图元 + 双击格式刷按钮）→ continuous →（可连续点击多个目标，各一条记录）
continuous →（Esc 或点击画布空白）→ off
```

- once/continuous 均以当前唯一选中图元为源；非单选时按钮禁用。
- 格式刷模式下游标变为十字（画布容器 `format-painting` 类），点击图元只应用格式、不改变选择；点击空白或 Esc 退出。
- 复制范围：填充/边框/阴影（节点样式全键）+ 字体/文本块/段落；边复制边样式全键；不复制位置/尺寸/旋转/内容/图片/链接/端口/业务数据/形状类型与组合容器关系；类型不匹配（节点源→边目标）的目标自动跳过。

### 超链接点击

- **普通点击**：选择图元（不打开链接）。
- **Ctrl（macOS Cmd）+点击带链接节点**：打开链接（经系统默认程序；此时不改变选择）。
- 链接在属性面板「链接」输入框设置/清除（失焦提交，一条「设置链接」记录）；仅支持 http/https/mailto，其他协议拒绝并提示「仅支持 http、https、mailto 链接。」。


### 文本编辑交互

- **进入**：双击节点、或选中单个节点按 F2/Enter，就地打开覆盖式编辑器（镜像当前字体样式，按文本区定位）；双击边编辑其首标签（无标签时提交即追加，position 0.5）。
- **IME 安全**：中文输入法组合过程（compositionstart→compositionend）不产生中间提交；组合中失焦挂起，上屏（compositionend）后再提交。
- **取消**：Esc 关闭编辑器，文档不变（不产生命令）。
- **提交**：失焦或 Ctrl/Cmd+Enter 提交；文本有变更才产生一条「编辑文本」记录（一次编辑会话一条），未变更不产生；Enter（无 Ctrl）在文本内换行。
- **编辑期间**：画布键盘快捷键（Delete/Ctrl+C/X/V 等）整体挂起，避免误删节点。
- **超长**：提交文本超过 10000 字符拒绝并提示「文本长度超出限制。」。

### 工具栏与属性面板 mixed 态

- 多选读取聚合值：全部一致显示该值；不一致显示「多个值」（文本/数字输入占位、下拉禁用项、布尔按钮不定态、颜色控件混合标记）；无文本目标时文本控件禁用。
- 任何控件一次写入 = 全部选中目标一条记录（撤销一步全部恢复）；含边选择时边首标签同批。
- 竖排为逐字排版（每字符一行），不用 transform 旋转整段文字。

## 键盘交互

- **Delete/Backspace**：删除选中图元（连带关联边，一条「删除图元」记录）。
- **Ctrl+C / Ctrl+X / Ctrl+V**（macOS Cmd）：复制/剪切先更新应用内剪贴板并 best-effort 写系统剪贴板；粘贴优先应用内，没有时读取系统 marker。系统权限或解析失败自动降级并提示，不阻断编辑；一次粘贴仍是一条历史记录。
- **F2 / Enter**（选中单个节点）：进入文本编辑。
- 输入框/文本编辑聚焦时上述按键不拦截；文本编辑进行中画布快捷键整体挂起。
- **菜单**：Tab 可到达 7 个顶级菜单；左右键切换顶级菜单，上下键切换项目，右键展开子菜单、左键返回，Enter/Space 执行，Esc 关闭并把焦点还给触发按钮。菜单打开后悬停另一顶级项会直接切换；点击外部关闭。
- **右键菜单**：方向键移动，右键展开对齐/分布子菜单，Enter 执行，Esc 关闭并把焦点还给画布。菜单会限制在当前视口内。
- **查找替换**：Esc 从右侧查找模式返回属性模式；查找下一个跨页循环定位。
- **Ctrl+A**：通过编辑菜单全选当前页，顺序为节点后连线。

## 菜单与右键

- 顶部菜单固定为文件、编辑、视图、插入、格式、工具、帮助。禁用项同时提供 `aria-disabled`、视觉弱化与中文原因 tooltip；勾选项同时显示勾号和文字状态。
- 文件、首选项、图片和窗口控制经 typed callback 进入 application controller；Vue 不调用 Tauri invoke、文件或 SQL API。文件工作流进行时相关菜单禁用；最近文件显示完整路径 tooltip。
- 右键上下文：空白提供粘贴/全选/页面设置；节点提供文本、链接、层序、组合和样式；边提供标签、链接和线条；多选提供格式刷、对齐、分布、自动连线和组合；容器提供成员与层序操作。执行统一进入 `MenuCommandController`。

## 对话框、覆盖层与焦点

- 「未保存的更改」、恢复、首选项和导出为模态对话框。打开后焦点进入对话框，Tab/Shift+Tab 在可操作项间循环；背景编辑区不可交互。关闭后焦点返回持久存在的菜单按钮或原触发控件。
- 功能帮助是非模态侧层，仍可看到编辑器；打开后聚焦关闭按钮，Esc 或关闭按钮退出。帮助只读取注册表，不修改选择、文档或历史。
- 菜单、右键菜单和查找模式同样以 Esc 关闭。菜单关闭返回顶级菜单按钮，右键菜单返回画布；恢复选择对话框的 Esc 不代替用户作出恢复或丢弃决定。
- 文件、恢复和导出执行中禁用会造成并发的输入与关闭动作，并显示「正在导出…」或对应忙碌状态。成功或失败均通过中文通知反馈。
- 选区框、Transform 手柄、端口、对齐辅助线、标尺、分页符、帮助和对话框均是覆盖层；除明确的编辑手柄外，它们不写入图文档。

## 查找替换

- 「工具→查找替换」打开右面板专用模式；输入 query 后即时报告匹配数量。范围可选当前页或全部页面，`Aa` 区分大小写，`Ab|` 使用 Unicode 字母/数字/下划线全词边界。大小写不敏感比较使用 locale 小写映射但不做 Unicode 规范化，因此保留重音差异；返回和替换位置始终是原始文本的 UTF-16 偏移。
- 只搜索节点文本和边标签，不搜索页面名、链接或业务数据。全部替换先显示数量和前 20 项，确认后以一条命令写入；一次撤销恢复全部原文。

## 帮助

- `feature-help-registry.ts` 是统一说明真源。非模态帮助侧层不遮断编辑，Esc/关闭按钮返回原焦点；显示帮助不修改文档或历史。
- 页面设置、文本格式、格式刷、连线、形状库、组合容器均有可键盘访问的 `?` 入口；菜单禁用原因使用 tooltip。

## 导出对话框

- 「文件→导出」打开模态对话框并把背景编辑器设为 inert；默认当前页、SVG 和文档名，PNG 默认采用首选项 DPI，但本次选择不会回写设置。
- 页面范围为当前页/全部页面；格式卡为 SVG/PNG/PDF/JSON；仅 PNG 显示 96/150/300 DPI。切换格式会清空已经选择的目标路径，避免扩展名与格式不一致。
- 「浏览」只经 platform adapter 打开原生保存选择器；取消选择不关闭对话框、不修改文档。导出进行中所有输入、帮助、关闭和取消均禁用，并显示「正在导出…」。
- 成功显示「已导出到 {path}」并发送全局通知；失败显示原始中文原因和检查保存位置、空间、权限的建议。Esc 等同取消；Tab/Shift+Tab 在对话框内循环；关闭后焦点返回「文件」菜单触发按钮。
- `?` 使用 `helpId=export` 打开统一帮助内容。导出是无文档写入的读取操作，不进入撤销历史。

## 状态机

画布工具状态与拖拽会话见上文「选择与拖拽状态机」。文本编辑会话状态机：

```text
Idle → 进入编辑（双击/F2/Enter） → Editing → 提交（失焦/Ctrl+Enter，有变更一条记录） → Idle
                                  ├→ Esc 取消（文档不变） → Idle
                                  └→ IME 组合中：挂起提交，compositionend 后结算
```

## 快捷键

完整菜单快捷键见应用「帮助→快捷键列表」；当前已接线：

| 快捷键 | 功能 |
|--------|------|
| Ctrl+Z（macOS：Cmd+Z） | 撤销 |
| Ctrl+Y（macOS：Cmd+Shift+Z） | 重做 |
| Ctrl+N / Ctrl+O / Ctrl+S / Ctrl+Shift+S | 新建 / 打开 / 保存 / 另存为（桌面处理器由 8b2 接入） |
| Ctrl+X / Ctrl+C / Ctrl+V / Ctrl+D | 剪切 / 复制 / 粘贴 / 重复 |
| Ctrl+A / Delete | 全选 / 删除 |
| Ctrl++ / Ctrl+- | 放大 / 缩小 |
| F2 / Enter | 编辑单个节点文本 |
| Esc | 关闭菜单、右键、帮助或查找模式；退出格式刷 |

## 文件、恢复与窗口关闭

- 新建、打开或关闭脏文档会显示「未保存的更改」，可选择保存、不保存或取消；保存选择器取消或保存失败时原动作不会继续。
- 未保存对话框使用焦点陷阱，Esc 等同取消，关闭后焦点返回触发控件。恢复对话框显示名称、更新时间和来源；Escape 不替用户决定，丢弃需要二次确认。
- 启动最多检查并显示一次最新恢复快照。恢复后文档保持 dirty，快照保留到显式保存成功；损坏快照被忽略并按 versionToken 条件删除。
- 自定义标题栏可拖动并调用原生最小化、最大化/还原和关闭。原生关闭事件先 `preventDefault`，等待同一脏文档工作流批准后才销毁窗口，避免递归关闭。

## 窄窗口与外观偏好

- 最小窗口为 960x600 CSS px。左侧图元库和右侧面板均可折叠；窗口宽度小于 1100px 时右侧面板改为 280px 的可关闭浮层，优先保留中央画布。
- 主题支持浅色、深色和跟随系统；高对比偏好使用系统颜色与可见轮廓，`prefers-reduced-motion` 时动画时长接近零。外观变化不修改图文档，也不进入撤销历史。
- 标尺、网格、参考线、分页符、吸附、默认缩放和单位等首选项写入本机设置。设置持久化失败时当前运行继续采用新值并显示通知。
