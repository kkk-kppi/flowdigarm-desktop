# 桌面流程图编辑器 实施计划

**版本：** 4.1  
**格式：** 混合格式（阶段里程碑 + 详细任务清单）（已对齐原型 HTML v2）

## 0. 实施前门禁

阅读 PRD、概要设计、详细设计、数据库设计、UI/交互规格、原型与图标物料；建立需求追踪表（需求→模块→文件→测试→验收）。任何冲突按"桌面端、pt、领域命令历史"优先处理。

## 1. 全局约束

- 仅支持 Windows 10/11 与 macOS（Intel/Apple Silicon）
- 图文件、X6 Cell 和导出逻辑统一以 pt 保存；CSS px 仅限渲染层
- `devicePixelRatio` 不进入文档、命中检测和撤销数据
- 一个文件只有一个清晰职责；不得创建聚合无关逻辑的 `utils.ts` 或 `editor-actions.ts`
- 每个用户行为只生成一条撤销/重做记录；X6 内置 History 不作为用户历史
- 当前阶段不实现泳道、Linux、多人协作、VSDX/BPMN 兼容和复杂全局避障

## 4. 变更纪律

每个任务按"失败测试→最小实现→通过测试→文档同步→提交"执行。功能逻辑放 application/domain，Vue 放 ui，X6/Tauri/SQLite 放 infrastructure。不得使用 X6 History 作为用户历史；不得把 pt 换算写入 UI。

## 5. 发布门禁

- 完成需求追踪表 100% 映射
- 单元/组件/Rust/E2E/性能通过
- README/features/interactions/user-guide 同步
- Windows/macOS 包签名验证
- 验收报告逐项标记通过、失败、未覆盖

## 6. 计划自检

- **规格覆盖**：标题栏、菜单栏、Ribbon、页面标签栏、形状库、属性面板、状态栏、页面设置、单位/标尺、分页符、形状/连线、文本、格式刷、链接、组合/容器、搜索、右键菜单、历史、持久化、导出与跨平台发布均有对应任务
- **依赖顺序**：P0 提供工程基础+UI骨架；P1–P2 提供模型与命令基础；P3–P4 提供画布和页面；P5–P7 构建编辑功能；P8 完成导出和交付
- **文件职责**：每个规划文件按单一功能拆分；无笼统工具或聚合动作文件
